## G08 證據與理性

### Claims

- **CL1** 解釋聖經必須找證據、用理性分析，才能得到經文正確的意思；不能把自己的主觀當作聖靈的感動，沒有證據等於沒講。
  - claim_kind: hermeneutical
  - related_ranges: L2-S0021, L2-S0022, L2-S0023, L3-S0010, L3-S0014
  - 頂層（本組主要結論之一）
  - **CL3** 聖經一句話只有一個意思；甲乙兩人都說聖靈感動，得出的解釋卻相反，不可能都是聖靈給的，所以許多人把自己的主觀當作聖靈的感動。
    - claim_kind: hermeneutical
    - related_ranges: L2-S0022
    - supports CL1
  - **CL4** 用正確的解經方法、根據證據所得的結論，每個人都應一樣；弗4:13「在真道上同歸於一」指靈命長進到每個人對聖經的認識都一樣、準確明白聖經的意思。
    - claim_kind: hermeneutical
    - related_ranges: L2-S0022
    - supports CL1
  - **CL5** 我們該做的事神不替我們做：要靠神給的能力，但該盡的本分（包括找證據明白聖經）要自己去做。
    - claim_kind: doctrinal
    - related_ranges: L2-S0023
    - supports CL1
    - **CL6** 聖靈很多時候是藉著聖經的教導引導人；不好好念聖經、只求聖靈直接告訴，是走捷徑（後現代的特徵），聖靈會叫你去看聖經。
      - claim_kind: doctrinal
      - related_ranges: L2-S0023
      - supports CL5
    - **CL7** 以為基督徒生活完全被動、什麼都不做才屬靈是錯誤觀念：新約書信的動詞約百分之四十多是命令式，是神要人去做的；靠著聖靈的幫助盡本分才是真正的基督徒生活。
      - claim_kind: doctrinal
      - related_ranges: L2-S0023
      - supports CL5
  - **CL8** 提後2:7「思想」原文 νοέω 是用理性去分析、思考、找證據；保羅要人用理性思考他所說的話，並說主在凡事上必給聰明。
    - claim_kind: exegetical
    - related_ranges: L2-S0023
    - supports CL1
  - **CL9** 解經是一切神學的根基：不會解經、找不出聖經的意思，神學不必念；協談最主要的幫助是把聖經真理搞清楚並應用在人的困難上，不只是傾聽的技術。
    - claim_kind: hermeneutical
    - related_ranges: L3-S0037
    - supports CL1

- **CL2** 信心與理性不相違反：有信心之後要用理性思考、分辨，才得到正確結論；理性的根基作為信仰的根基非常重要，以為講理性就是不屬靈是錯誤的。
  - claim_kind: apologetic
  - related_ranges: L3-S0019, L3-S0023, L3-S0024, L6-S0008
  - 頂層（本組主要結論之一）
  - **CL10** 現今許多人所謂的理性並不是真理性：他們先預設宇宙沒有超自然、沒有神，再用理性解釋聖經的現象，這是偏見；有沒有神、有沒有超自然應是找證據後的結論，不應是預設立場。
    - claim_kind: apologetic
    - related_ranges: L3-S0018, L3-S0013
    - supports CL2
  - **CL11** 一個人「迷信」有神沒有資格拿 PhD；但根據證據相信有神是學術，不是迷信。
    - claim_kind: apologetic
    - related_ranges: L3-S0015, L3-S0016, L3-S0017
    - supports CL10
  - **CL12** 林後10:5「將人所有的心意奪回」的「心意」原文是理性：保羅傳福音的方法是攻破攔阻人認識神的計謀，奪回人的理性使它順服基督；所以以為有理性就不屬靈是錯的。
    - claim_kind: exegetical

  - **CL13** 教導與傳福音不能只講要相信什麼，還要講為什麼、給人看證據；沒有客觀證據會產生很多問題，不好好教導青年人有理性的根基、有證據，真的很危險（許多青年進大學後離開信仰）。
    - claim_kind: practical

    - **CL14** 基督徒要懂得處理聖經的證據、分辨並回應不懂聖經者（如 Time Magazine 記者）的亂講，被人問時能講清楚，才不會被問倒。
      - claim_kind: apologetic
      - related_ranges: L2-S0016
      - supports CL13

## G09 離婚與再婚

### Claims

- **CL15** 按照聖經的教導，離婚之後可以再婚，男女一樣。
  - claim_kind: ethical
  - related_ranges: L4-S0006, L4-S0007, L4-S0010, L4-S0013
  - 頂層（本組主要結論之一）
  - **CL16** 太5:32「叫她做淫婦」：被休而不再婚的女人並沒有成為淫婦；古時女人只能靠父親供養或再婚才活得下去，所以耶穌是說，不是為淫亂的緣故休妻，就是逼她再嫁別人；再婚在當時理所當然，所以保羅也沒有提離婚後可以再婚。
    - claim_kind: exegetical
    - related_ranges: L4-S0006, L4-S0013
    - supports CL15
  - **CL17** 約4:17-18 耶穌說撒馬利亞婦人「已經有五個丈夫，現在有的並不是你的丈夫」，區分了再婚的丈夫與只是同居的非丈夫，表示耶穌承認再婚。
    - claim_kind: exegetical
    - related_ranges: L4-S0006, L4-S0013
    - supports CL15
  - **CL18** 申24:1-4：古時休書必須寫明「休你之後你可以自由嫁人」才有效，經文也明說婦人離開夫家可以嫁別人（例外是前夫不可在她再嫁後再娶她），表示當時認為離婚後再婚是理所當然的。
    - claim_kind: exegetical
    - related_ranges: L4-S0007, L4-S0013
    - supports CL15
  - **CL19** 再婚不一定就是犯淫亂：再婚後第一次的性關係算是犯姦淫，但正式結婚之後她已是你的妻子，就不再是犯姦淫。
    - claim_kind: ethical
    - related_ranges: L4-S0010
    - qualifies CL15
  - **CL20** 現在離婚之後不再婚也可以活下去，與古時情況不一樣；但保羅說，不能節制就當嫁娶，與其慾火攻心倒不如嫁娶（林前7:9）。
    - claim_kind: ethical
    - related_ranges: L4-S0010
    - qualifies CL16
  - **CL21** 未婚姊妹嫁給離過婚的人，不一定絕對不可以：若當初是男方的錯，要看他是否真的悔改，不悔改就不要再婚；姊妹也要先在心理上能接受他結過婚的事實才結婚，不要馬上結婚。
    - claim_kind: ethical
    - related_ranges: L4-S0011
    - qualifies CL15
  - **CL22** 離過婚的人再婚後再離婚的機率較高，所以教會有責任好好教導再婚者，使新家庭穩固；教會不應只要離過婚就不肯接受，應了解離婚的緣故是誰的錯。
    - claim_kind: practical
    - related_ranges: L4-S0007, L4-S0008
    - qualifies CL15

- **CL23** 離婚不是好事，離婚是惡；但在某種情況底下，離婚是比較小的惡。
  - claim_kind: ethical
  - related_ranges: L4-S0003, L4-S0006, L4-S0009, L4-S0010
  - 頂層（本組主要結論之一）
  - **CL24** 林前7:15：已婚者一方信主後，不應因此休掉不信的配偶；但不信的一方要離去就讓他走，信的弟兄姊妹在這情況下 no longer bound，不再受婚約約束；能維持更好，「神召我們原是要我們和睦」是猶太人的表達法，意思是盼望那不信的配偶能信主。
    - claim_kind: exegetical
    - related_ranges: L4-S0002, L4-S0011
    - supports CL23
    - **CL25** 未婚的人不要跟不信的人結婚：婚姻本身就很難，信與不信的價值觀完全不同，一起生活更困難；保羅說「不要同負一軛」是為我們的好處。
      - claim_kind: ethical
      - related_ranges: L4-S0002
      - qualifies CL24
  - **CL26** 耶穌說「起初並不是這樣」（太19、可10）與路16:18 講的是理想的原則：婚姻是一輩子，不能離婚，這原則絕不改變；摩西因人心硬才許寫休書；人心硬、不聽神的話時，才出現大惡小惡的問題，保羅是把耶穌的原則用在實際情況。
    - claim_kind: exegetical
    - related_ranges: L4-S0009, L4-S0010
    - supports CL23
  - **CL27** 做倫理抉擇時常常逃不掉大惡、小惡的問題，人生當中不可能避免；例如政府的要求與神的命令衝突時，寧可順從神而違背政府。
    - claim_kind: ethical
    - related_ranges: L4-S0009
    - supports CL26

- **CL28** 多妻違反聖經原則；但宣教時酋長已多妻信主，不應要求他休掉其他妻子只留元配——倫理抉擇必須考慮既成事實（如保羅說已與不信者結婚的不要因信主休掉對方）；多妻不是好的見證，所以不可作長老、教會領導者；多妻與再婚的情況不一樣。
  - claim_kind: ethical
  - related_ranges: L4-S0011
  - 頂層（與上兩結論不從屬的另一判斷）

- **CL29** 讀聖經必須了解當時的背景與文化情況，才能正確了解聖經的意思；我們習慣了現在的情況而忘記古時情況，會引起對聖經的錯誤觀點。
  - claim_kind: hermeneutical
  - related_ranges: L4-S0013
  - 頂層（本組由案例得出的一般讀經原則）

- **CL30** 考慮事奉時必須考慮所去之處的情況與事奉的效果（如1970年台灣教會不接受離婚者擔任工作，現在態度改變，會評估離婚的緣故）。
  - claim_kind: practical
  - related_ranges: L4-S0008, L4-S0011
  - 頂層（由案例得出的事奉原則）
  - **CL31** 領導力是對別人的影響，人對你的尊敬是你贏得的，不是因為被派到某個職位；牧者到教會要先贏得人的尊敬，工作才有效。
    - claim_kind: practical
    - related_ranges: L4-S0011
    - supports CL30

### Questions

## G10 兩害取其輕

### Claims

- **CL27**（existing CL27）做倫理抉擇時常常逃不掉大惡、小惡的問題，人生當中不可能避免；例如政府的要求與神的命令衝突時，寧可順從神而違背政府。
  - claim_kind: ethical
  - related_ranges（追加）: L4-S0004, L4-S0005
  - 頂層（本組主要結論，沿用）
  - **CL32** 有時無論走哪一條路都是惡，無法避免一切的惡，那時只能選擇比較輕的惡去做；說「惡就是惡，絕不能做」的人是沒有看到聖經的證據。
    - claim_kind: ethical
    - related_ranges: L4-S0004
    - supports CL27
  - **CL33** 彼得在彼前2:13教導要順服人的一切制度，但公會禁止他奉耶穌的名講道時，他寧可順從神；違背公會是惡，不聽神的話是更大的惡，所以他選擇小的惡。
    - claim_kind: exegetical
    - related_ranges: L4-S0004
    - supports CL32
  - **CL34** 喇合撒謊是惡，把兩個探子交出來被殺是更大的惡，所以她選擇小的惡；聖經沒有因她撒謊定她的罪，神拯救她，她後來成為耶穌的先祖。
    - claim_kind: exegetical
    - related_ranges: L4-S0004
    - supports CL32
  - **CL35** 分辨哪個是大惡、哪個是小惡，要從客觀的情境、從神的整個公義去看；當事人自己決定比較難（如牙痛時說寧可死），應找屬靈的長者討論，幫助自己思考。
    - claim_kind: ethical
    - related_ranges: L4-S0005
    - qualifies CL32
    - **CL36** 胎兒檢查出僅有可能有問題時，不要墮胎：墮胎是把一個生命墮掉，當然是惡；孩子生下來真的有問題時，可考慮送到專門收養這種孩子的地方；這時要找別人、組內長者一起分析決定。
      - claim_kind: ethical
      - related_ranges: L4-S0005
      - supports CL35
