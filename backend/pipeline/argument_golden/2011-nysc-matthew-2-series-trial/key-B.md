## G08 證據與理性

- **K1 明白聖經要靠證據和理性分析，不能把自己的主觀當作聖靈的感動或「亮光」。**
  - K1.1 一節聖經只有一個意思；甲乙兩人都說聖靈感動自己，得到的意思卻完全相反，這不可能，可見有人把主觀當作聖靈。
  - K1.2 所以要學解經、要找證據；用正確的解經方法、根據證據得出的結論，每個人都應該一樣。
    - K1.2.1 保羅說靈命長進的結果是「在真道上同歸於一」（弗四13），也就是每個人對聖經的認識都一樣、準確明白它的意思。
    - K1.2.2 觀點不同時，不是吵架而是找證據；對方看了證據，看法就一致了。
  - K1.3 我們該做的事，神不替我們做：要靠神的幫助，但要盡自己的本分；找證據、得出正確結論就是我們的本分。
    - K1.3.1 保羅吩咐「我所說的話你要思想」（提後二7），νοέω 的意思是用理性分析、思考、找證據，不只是「思想」。
    - K1.3.2 聖靈常是藉著聖經的教導來引導人；不讀聖經、只要聖靈直接告訴你，是後現代想走捷徑。
    - K1.3.3 書信裡約百分之四十多的動詞是命令式；如果基督徒什麼都不必做、完全被動才算屬靈，這些經文就可以丟掉了。
  - K1.4 「解經是一切神學的根基」：不會把聖經的意思找出來，神學就不必念，因為神學必須建立在聖經真理上。
    - K1.4.1 真正的協談幫助，是把聖經真理搞清楚並應用在對方的困難上，光有傾聽的技巧不夠；可惜很多神學院輕看解經，花許多時間教協談技術。
- **K2 信心和理性不衝突；信仰需要理性的根基，教導和傳福音不只講「信什麼」，還要用證據講「為什麼信」。**
  - K2.1 基督徒要懂得處理聖經的證據，才能分辨、回應不信的人（例如新聞記者）亂講，不會被人問倒。
  - K2.2 所謂「理性」的不信派，是先預設宇宙沒有神、沒有超自然，再來解釋聖經，這是有偏見的理性。
    - K2.2.1 真正的理性沒有預設立場：有沒有神、有沒有超自然，應該是找證據之後的結論，不是預設立場。
    - K2.2.2 迷信有神沒有資格拿 PhD，但根據證據相信有神是學術，不是迷信。
  - K2.3 保羅傳福音就是要攻破攔阻人認識神的計謀，把人的理性奪回、使它順服基督（林後十5，「心意」原文是「理性」）；教會以為講理性就是不屬靈，是錯的。
  - K2.4 沒有客觀證據的信仰會出問題：很多在教會長大的年輕人進大學後離開主（他估計約七成到八成，有人說九成）；教會教導他們證據，他們就能站立得穩。
  - K2.5 信心要用理性去思考：亞伯拉罕按邏輯推理，神應許子孫要從以撒而出，以撒還沒有生子，神卻叫他獻以撒，所以神會叫以撒復活；聖經說他就像從死裡得回以撒。

## G09 離婚與再婚

- **K3 離婚是惡，但在某些情況下是比較小的惡；神設立的婚姻是一輩子的理想原則，保羅把這個原則應用在實際情況中。**
  - K3.1 婚姻是神設立的神聖制度，耶穌說不要隨便離婚（太五32）。
  - K3.2 林前七15：信主之後，不信的一方要離去就由他去，「不必拘束」的意思是不再受婚約約束（no longer bound）；但能維持更好，因為「神召我們原是要我們和睦」，就是盼望對方信主。
    - K3.2.1 未婚的人不要與不信的人結婚（「信與不信原不相配」），因為兩人的價值觀不同，婚姻更難。
    - K3.2.2 已婚後才有一方信主的，不要因此休掉對方。
  - K3.3 太十九、可十、路十六18：耶穌講的是理想原則（結婚是一輩子，不能離婚）；摩西准許休妻是「因為你們心硬」。人不完全遵行神的話，就出現大惡、小惡的問題，做倫理抉擇時逃不掉這個問題（例如政府的要求違背神時，寧可順從神）。
- **K4 照聖經的教導，離婚之後可以再婚，男女都一樣。**
  - K4.1 太五32「叫她做淫婦」的意思：被休而沒有再婚的女人並沒有成為淫婦；古時女人只能回父家或再嫁才能活，不是因為淫亂而休妻，就是逼她再嫁。
  - K4.2 古時離婚後再婚是理所當然的事，所以經文（包括保羅）不必特別提再婚。
  - K4.3 耶穌承認再婚：撒馬利亞婦人「已經有五個丈夫，現在有的並不是你的丈夫」（約四17–18），耶穌分別了再婚的丈夫和同居的非丈夫。
  - K4.4 申二十四1–4：休書必須寫明她可以自由再嫁，否則無效；經文明講婦人離開夫家後可以去嫁別人，例外只是前夫不可再娶她回來。
  - K4.5 讀聖經必須了解當時的文化背景；習慣了今天的情況而忘記古時的情況，就會誤解聖經。
- **K5 再婚、與離過婚的人結婚、教會接納，這些實際問題要根據情況評估，不能一概定罪。**
  - K5.1 再婚不是一直犯姦淫：再婚後第一次的性關係算犯姦淫，但正式結婚後她已經是你的太太，就不再是犯姦淫。
  - K5.2 未婚姊妹與離過婚的人結婚不一定不可以：若是男方的錯，要看他是否真的悔改；姊妹也要先在心理上接受他結過婚的事實，再結婚。
  - K5.3 多妻違反聖經原則，但倫理抉擇要考慮既成事實（不能叫信主的酋長休掉其他妻子，使她們和孩子無法生活）；因為見證不好，所以不可作長老。再婚與多妻的情況不同。
  - K5.4 離過婚的人再婚，再離婚的機率比較高，所以教會有責任好好教導，使新家庭穩固；只要離過婚就不肯接納，那更慘，教會應該查明離婚的緣故。
  - K5.5 考慮事奉時，要考慮所去之處的情況和事奉的效果；領導力是贏得的，不是靠職位。

**材料（不是提綱上的點）**
- 經文：太五32；林前七9、七15；林後六14（不要同負一軛）；約四17–18；申二十四1–4；太十九3–9；可十2–12；路十六18。
- 「上課不必提醒你呼吸」的 take for granted 比喻；美國遺囑必須寫明取消以前的遺囑，比照休書必須寫明可以再嫁。

- 一位離婚姊妹：1970 年左右他勸她不要回台灣服事，她就留在美國，奉獻支持台灣的神學生；約三十年後退休，台灣教會態度已改變，神學院調查她離婚的緣故後接納她任教。

## G10 兩害取其輕

- **K6 有時無論走哪一條路都是惡，避免不了；這時只能選擇比較輕的惡，聖經裡有這樣的證據。**
  - K6.1 彼得教導要順服人的一切制度（彼前二13），但公會禁止奉耶穌的名講道時，他寧可順從神；違背公會是惡，但違背神是更大的惡。
  - K6.2 喇合撒謊是惡，但交出探子讓他們被殺是更大的惡，所以她選擇比較小的惡；聖經沒有定她的罪，神拯救了她，她還成為耶穌的先祖。
  - K6.3 所以在某些情況下，離婚是比較小的惡，只有離婚，保羅也明講有這個可能。
- **K7 判斷哪一個是大惡、哪一個是小惡，要從客觀的情境和神整體的公義來看；當事人自己難以判斷，應該找屬靈長者一起討論、分析。**
  - K7.1 當事人在痛苦中判斷會失準（牙痛時說「死了更好」，好了才慶幸沒死）。
  - K7.2 墮胎的例子：只因檢查出孩子「可能」有問題，不要墮胎；墮胎是殺掉一個生命，是惡。孩子生下來真有問題，還可以送到專門收容這類孩子的機構，這也是可以考慮的選項。

## G11 起誓

- **K8 耶穌說「不要起誓」，意思是不要用起誓來騙人，不是任何情況下都不可以起誓。**
  - K8.1 神自己也起誓：神給亞伯拉罕應許時，沒有比祂更大的可以指著起誓，就指著自己起誓（希伯來書）。
  - K8.2 大祭司要耶穌起誓回答是不是神的兒子，耶穌就回答「你說的是」。
  - K8.3 太二十三：法利賽人用起誓騙人，指著聖殿起誓卻不守，再說要指著聖殿的金子起誓才算數；耶穌禁止的是這種做法。

## G12 以眼還眼與愛仇敵

- **K9 「以眼還眼，以牙還牙」不是舊約的個人道德標準，而是審判官定罪量刑的原則；差別在個人倫理與社會倫理，不在舊約倫理與新約倫理。**
  - K9.1 常見的錯誤說法：舊約道德是以眼還眼，新約的標準比這更高，要愛仇敵。
  - K9.2 這句話在舊約出現三次（出二十一22–25、利二十四13–23、申十九15–21），都與司法有關，是審判官衡量懲罰的原則。
  - K9.3 舊約也教導以愛待仇敵：仇敵餓了給他吃，渴了給他喝；新舊約都一樣。
  - K9.4 耶穌糾正的是猶太人把審判原則誤用在個人報仇上；新約中這仍是社會倫理的標準，個人則要愛仇敵。
- **K10 「右臉被打，連左臉也轉過來」是誇張說法（hyperbole），意思是不要與惡人作對，不一定要以牙還牙（get even）。**
  - K10.1 耶穌在大祭司面前被差役打（約十八22），沒有轉另一邊臉給他打。
  - K10.2 保羅受審時大祭司亞拿尼亞吩咐人打他的嘴（徒二十三2），他也沒有轉臉讓人打。
  - K10.3 若照字面執行會出問題：兒子無緣無故打你，你應該管教他，而不是轉臉讓他打。
- **K11 基督徒要以愛待人；愛不是做別人喜歡的事，而是做對他真正有幫助的事（有人需要管教，管教才是愛他）。以愛對待惡待你的人，可能把他挽回，人際關係也更好。**

**材料（不是提綱上的點）**
- 經文：太五38–41；出二十一22–25；利二十四13–23；申十九15–21；約十八21–22；徒二十三2。
- 中國人的誇張語：「高興死了」「氣死了」。
- Pat 的故事：他任 Division Chair 時，因信仰問題不聘一位女性應徵者，一位副教授罵他；當晚他先問候「Pat, how are you?」，對方躲到教室哭了一晚，一個月後在教授會議上公開道歉，此後十幾年支持他的提議。
- 美國學生因論文英文被他修改而罵他（「英文是我的母語」），他平靜回應，學生後來態度轉變。

## G13 墮胎

- **K12 出二十一22 講的不是墮胎，不能用它證明墮胎不等於殺人；墮胎是惡，只有在不墮胎母親就會死的情況下，墮胎才是值得考慮的比較小的惡。**
  - K12.1 出二十一22 那個字是「早產」，不是「墮胎」；相鬥造成婦人早產，孩子若受傷就要照審判官所斷定的賠償，這是定罪量刑的標準。
  - K12.2 胎兒在母腹中已經存在，也是一個人。
  - K12.3 胎兒什麼時候成為人，要從醫學方面找證據：受精卵有許多沒有著床就流掉，那不是人；著床之後雖然還不是完整的人，但有成為完整的人的潛力，殺掉就出問題了。
  - K12.4 為救母親的生命而墮胎是比較小的惡：墮胎是惡，讓母親死是更大的惡。
  - K12.5 應用聖經原則處理倫理問題，也需要醫學等方面的知識；知道的資料越多，越能做正確的決定。

**材料（不是提綱上的點）**
- 會眾提問：有人根據出二十一22 說墮胎和殺人不一樣；可否用出二十一12「打人以致打死的，必要把他治死」推論墮胎等於殺人。
- 「有些神學道德學家」主張著床前不算人。
- 回指前一天講的「比較小的惡」。

**沒有回答的問題**

## G14 行為就是禱告

- **K13 我們的行為是禱告的一部分：禱告一種是用口說，一種是用行為表達禱告的內容。**
  - K13.1 太六8到七11 構成一個講禱告的 inclusio：六8「你們沒有祈求以前……父早已知道」，七7–11「神必垂聽禱告」，所以整段是一個單元，講禱告。
  - K13.2 段中六9–13 是主教導我們的禱告文（不是「耶穌的禱告」，The Lord's Prayer 的譯法不太準確），六19到七6 講我們的行為，可見行為也是禱告。
  - K13.3 口裡的禱告和行為不一致，神要聽哪一個？
  - K13.4 主禱文的內容決定相應的行為：
    - K13.4.1 「願人都尊你的名為聖」就是「願人都把你當作神」；把神當作神，價值觀就改變，生命中最有價值的是神，所以會積攢財寶在天上。口裡這樣禱告，卻把財寶積在地上，不為永恆積蓄，這禱告就是假的。
    - K13.4.2 「願你的國降臨，願你的旨意行在地上」：神的國就是神作王；真這樣禱告，就會積攢財寶在天上，並且對神有專一的心，因為只有神最重要。
  - K13.5 不看經文的結構（inclusio）就看不出這一點。

**材料（不是提綱上的點）**
- inclusio 的定義：一段經文開頭和結尾的字或觀念相同（前一天提過）。
- 「主禱文」與 The Lord's Prayer 的名稱。
- 糖尿病的例子：口裡求神醫治，行為上卻天天吃糖。

**沒有回答的問題**
- （無）

## G15 神蹟與信心

- **K14 馬可福音最後一段說喝毒、拿蛇不受害，不是說有信心的人故意去喝毒、拿毒蛇也不會死。**
  - K14.1 第一個問題：早期抄本中馬可福音到十六8「因為他們害怕」就結束了，九至二十節是很晚的抄本才有。
  - K14.2 第二個問題：這段的意思是神有時顯神蹟保守人，例如人在不知情或被迫的情況下碰到毒、被毒蛇咬，神可以使毒不發作，就像保羅在米利大島被毒蛇咬沒有死；故意喝毒一定會死。
  - K14.3 沒把聖經讀清楚，就產生極端做法，破壞教會的見證。
- **K15 信是有內容、有對象的（信耶穌基督），不是「信一信就有」。**
  - K15.1 希伯來書十一1「信是所望之事的實底」常被誤讀成：相信自己有了，就會有。
  - K15.2 信要有四千萬美金、信自己有丈夫，並不會因此就有。

**材料（不是提綱上的點）**
- 會眾提問把經文記成路加福音，他更正為馬可福音最後一段。
- 肯塔基礦工社區的教會在聚會中傳遞毒蛇，許多人被咬死。
- 保羅在米利大島拾柴被毒蛇咬（使徒行傳）。
- 許牧師當天講的話和例子（四千萬美金、未婚女孩信自己有丈夫）。

**沒有回答的問題**
- （無）

## G16 計畫與憂慮

- **K16 經文說的是不要憂慮，不是不要籌劃；為將來計劃、預備是應該的。**
  - K16.1 憂慮是沒有理由地憂慮，憂慮沒有用；為退休後的生活計劃、預備不是憂慮。
  - K16.2 有人把這個字讀錯，以為不可以籌劃，就從不為退休計劃，還以為這是信心；那不是信心，而是亂來。

**材料（不是提綱上的點）**
- 錄音開頭的介紹：2011 年紐約夏令會、紐約靈命晉升會、講壇錄音事奉、第六講《馬太福音釋經（二）：登山寶訓》。
- 經文：太六25–34（讀經）。

**沒有回答的問題**

## G17 論斷與評估

- **K17 倚靠神、求日用的飲食就不必憂慮，但仍要盡本分為退休後的生活計劃、預備；這樣計劃並不是沒有信心。**
- **K18 「不要論斷人」不是不要評估人：論斷是沒有證據就判定一個人好或壞（prejudge），評估是根據證據衡量；聖經禁止論斷，卻要我們評估。**
  - K18.1 主禱文「免我們的債」與七1–8「不要論斷人」平行：求神免我們的債，就不要論斷別人。
  - K18.2 同一段的七6「不要把聖物給狗，不要把珍珠丟在豬前」：不評估就無法知道誰是狗、誰是豬，所以不要論斷不可能是不要評估；經文前後文絕不會衝突。
  - K18.3 論斷是還沒有證據就先認定一個人是好人或壞人；評估是找證據、根據證據衡量。人如果不評估，根本無法在世上生活。

**材料（不是提綱上的點）**
- 公司老闆考核員工被當成論斷的例子。
- 教授每學期給學生打 A 到 F 的玩笑，有學生信以為真。
- 英文 prejudge 與 judge。

**沒有回答的問題**
- （無）

## G18 林前十13 是警告

- **K19 林前十13 是神的警告，不是應許：神允許臨到你的試探，神負責開出路；你自己招來的試探要自己負責，犯了罪神會懲罰。**
  - K19.1 主禱文「不叫我們遇見試探」：試探避免不了，意思是不要遇見超過我們所能承受的試探。
  - K19.2 若十13 是應許（試探時神總會開出路叫你忍受得住），基督徒就不會犯罪；事實上許多基督徒受試探就垮了。
  - K19.3 前後文決定它是警告：十11 是警告，十12 是警告，十14「要逃避拜偶像的事」也是警告，而十13 與十14 是用「所以」連接的（中文沒有譯出）。
    - K19.3.1 「應許」加「所以要小心」講不通，就像說：「我有清潔劑能輕易洗掉手上的墨水，所以你們要特別小心，不要讓墨水沾在手上。」
  - K19.4 讀經要用理性看前後文、憑證據，不要憑「亮光」；A 和 B 得到的亮光完全相反，不可能兩個都是亮光，一節經文也不會有兩個相反的意思。

**材料（不是提綱上的點）**
- 經文：林前十11–14（讀經）；十11 說曠野的事是警戒「我們這末世的人」，末世從耶穌降生、第一世紀就開始了。
- 他估計八成到九成以上的基督徒（包括牧師、佈道家、神學院老師）把十13 當作應許。
- 旅館夜班的例子：一位弟兄午夜後與年輕漂亮的女同事關在房間裡算現款，還引這節經文說要繼續做；他要對方當天辭職，後來對方辭了。

**沒有回答的問題**
- 會眾問：「一個試探到底是神讓你遇見的，還是你自己招來的？」他只說「可以分得很清楚」，沒有說明怎麼分辨。

## G19 希伯來的說法

- **K20 聖經說「神使……」（如神使法老心硬、神給人悔改的心），常是猶太人的說法：把神所造之律的作用說成是神做的，不是說神先強使人那樣。不懂這種說法，就會誤以為神不公義。**
  - K20.1 東西掉下來是地心引力，地心引力是神造的，所以聖經會說神叫它掉下來。
  - K20.2 法老心硬：出七13、七22、八15、八19、八32、九7 都說法老自己心硬；法老硬心六、七次之後，經文才第一次說耶和華使法老心硬，之後又交替出現。所以不是神先叫法老心硬。
  - K20.3 人越犯罪心越剛硬（第一次撒謊心跳加快，第一百次面不改色）；這條心理律是神造的，所以照聖經的說法，神叫所有犯罪、撒謊的人心剛硬。
  - K20.4 提後二25「或者神給他們悔改的心」：意思是你用溫柔勸戒抵擋的人，他或許會悔改；這不是說我們溫柔與否會影響神給不給人悔改的心，因為聖經明講，神的心意是把悔改的心給所有人。
  - K20.5 不懂這種說法，就像外國人把中國人說的「高興死了」當真。

**材料（不是提綱上的點）**
- 會眾舉的例子：撒下二十四1（耶和華激動大衛數點百姓）與代上二十一1（撒但激動大衛），會眾認為是從不同角度得出不同結論。
- 羅九「要叫誰剛硬就叫誰剛硬」，以及「這樣的神公義嗎」的質疑。
- 他現場讓物件掉落示範地心引力；說自己眼睛不好，請會眾讀經。
- 經文：出七13、22；八15、19、32；九7；提後二25。

**沒有回答的問題**
- 撒下二十四1 與代上二十一1 對激動大衛的是誰說法不同，他只說「那是猶太人的觀念」，然後轉到地心引力與法老，沒有具體說明這兩節怎麼對應，例如經文中「撒但」的角色。
