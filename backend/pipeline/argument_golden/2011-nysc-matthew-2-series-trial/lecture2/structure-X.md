# Structure X: Claims only

## H1 律法的矛盾？新舊約的關係
- H1-CL1 耶穌一方面說律法和先知到約翰為止、有些摩西律法不必再遵守，一方面又在五19–20 說遵行並教訓人遵行這誡命的在天國要稱為大、人的義要勝於文士和法利賽人的義；兩方面看來矛盾。

## H2 從「宗主國之約」理解聖經
- H2-CL1 要回答這矛盾，必須從「約」的觀念來看：舊約、新約講的都是宗主國與附庸國之約——宗主國先恩待附庸國，然後對它有所要求。
- H2-CL2 附庸國遵守宗主國的要求不能建立好關係，只能維持宗主國先恩待它而已有的好關係；不遵守，約就破裂。 supports H2-CL1

## H3 舊約的摩西律法 vs. 新約的基督律法
- H3-CL1 舊約中神向以色列的要求是摩西的律法；新約中神向基督徒的要求是基督的律法。
- H3-CL2 舊約是神先把以色列從埃及為奴之家領出來施恩，然後在西乃山頒佈十誡提出要求：先施恩、後要求。 supports H3-CL1
- H3-CL3 保羅說他不在摩西律法之下，乃在基督的律法之下；基督徒是在基督的律法底下。 supports H3-CL1

## H4 兩律法的重疊：同一位神的要求
- H4-CL1 舊約的神與新約的神是同一位，所以摩西的律法和基督的律法有重疊的地方；不重疊的部分，如獻祭、潔淨與不潔淨的食物，基督的律法不管。
- H4-CL2 神向祂子民的要求，都是為著祂子民的好處。 supports H4-CL1
- H4-CL3 基督徒只要遵守基督的律法，就是摩西律法「正當的要求」，不是整個律法；保羅從來沒有說基督徒要遵守摩西律法。 supports H4-CL1
- H4-CL4 羅十三9–10、林前六9–10 這些看起來像要基督徒遵守摩西律法的經文，其實說的是兩律法重疊的部分，不是要基督徒遵守摩西律法。 supports H4-CL1
