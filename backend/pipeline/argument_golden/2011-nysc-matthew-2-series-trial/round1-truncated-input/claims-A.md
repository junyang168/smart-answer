## G05 基督徒與摩西律法

### Claims

- **CL18** 基督徒已經不在摩西的律法（舊約）底下，乃在新約、在基督的律法底下；基督的律法與摩西的律法有重疊的地方，所以看起來好像基督徒還要遵守摩西律法，其實不是。
  - claim_kind: doctrinal
  - related_ranges: L2-S0002, L2-S0003, L2-S0004, L2-S0005, L2-S0006, L2-S0007, L2-S0017
  - 頂層（主要結論）
  - **CL19** 張力：耶穌一方面說「律法的一點一畫也不能廢去」（五17–18）、「無論何人廢掉這誡命中最小的一條……在天國要稱為最小的」（五19–20）；另一方面耶穌潔淨了所有的食物、基督一次獻上永遠的贖罪祭，律法和先知到約翰為止，表示摩西律法至少有一部分在耶穌來了以後不必遵守。兩方面看起來矛盾。
    - claim_kind: tension
    - related_ranges: L1-S0008, L1-S0009, L2-S0001, L2-S0017
    - supports CL18（CL18 是他對此張力的解答）
    - **CL20** 摩西律法至少有一部分，耶穌來了以後就不必遵守：耶穌潔淨了所有的食物（可七19），所以不必再分潔淨與不潔淨的食物；基督一次獻上永遠的贖罪祭（來十12–14），所以不必再照摩西律法獻贖罪祭。
      - claim_kind: exegetical
      - related_ranges: L1-S0008, L1-S0009
      - supports CL19
    - **CL21** 五18 原文是「律法的一點一畫也不能廢去，直到成全」（heōs an panta genētai），不是「都要成全」；「成全」意思是都要發生（參太廿四34）。很多人略過「直到成全」，只讀成律法的一點一畫絕不能廢去，因而解作舊約律法今天還要遵守。
      - claim_kind: exegetical
      - related_ranges: L1-S0008
      - qualifies CL19（限定張力一方的讀法）
    - **CL22** 讀聖經要用理性去思考、分析，不要不想就看過去；這樣才能找出很重要的真理。
      - claim_kind: hermeneutical_principle
      - related_ranges: L1-S0008
      - supports CL19
  - **CL23** 宗主國與附庸國之約（Suzerain-Vassal Covenant）的兩個要素是施恩與要求：宗主國先恩待附庸國，然後提出要求；附庸國遵守要求不能建立好關係，只能維持既有的好關係；不遵守，約就破裂。
    - claim_kind: doctrinal
    - related_ranges: L2-S0002, L2-S0003
    - supports CL18
  - **CL24** 舊約是神先把以色列人從埃及領出來，然後在西乃山提出要求，就是摩西的律法；新約是神恩待基督徒，向基督徒的要求，保羅稱為「基督的律法」。
    - claim_kind: doctrinal
    - related_ranges: L2-S0003, L2-S0004
    - supports CL18
  - **CL25** 舊約的神和新約的神是同一位，祂的要求都是為子民的好處，所以摩西的律法和基督的律法有重疊的地方；不重疊的部分，如獻祭、潔淨與不潔淨的食物，基督的律法不管。
    - claim_kind: doctrinal
    - related_ranges: L2-S0005, L2-S0007
    - supports CL18
    - **CL26** 羅八4「律法的義」應譯「律法正當的要求」，不是整個律法，就是基督的律法；羅十三9–10、林前六9–10 所列的誡命是摩西律法與基督律法重疊的部分，所以看起來好像基督徒還要遵守摩西律法，其實不是。
      - claim_kind: exegetical
      - related_ranges: L2-S0006, L2-S0007
      - supports CL25
  - **CL27** 十條誡也是摩西律法的一部分，基督徒也不在十條誡底下；說「禮儀的律法不必守，但還要守十條誡」是錯的，會墮入安息日會、耶和華見證人要人守安息日的圈套。但這不表示可以犯姦淫、殺人、拜偶像，因為這些是基督的律法與摩西律法重疊的部分。

  - claim_kind: exegetical
  - related_ranges: L2-S0017
  - 頂層（與 CL18 互不從屬）

## G07 五28 動淫念

### Claims

- **CL31** 太五28 不是說看見異性覺得漂亮就已經在心裡犯姦淫；耶穌乃是說，看見婦女，為了「要」——意志上決定要跟她行淫、採取行動——雖然還沒有做，在那時心裡已經與她犯姦淫了。
  - claim_kind: exegetical
  - related_ranges: L3-S0002, L3-S0003, L3-S0009, L3-S0032, L3-S0036, L2-S0015, L2-S0024
  - 頂層（主要結論）
  - **CL32** 馬太所用 πρὸς τὸ + 不定詞的表達法，表達目的，不是表達後果。
    - claim_kind: exegetical
    - related_ranges: L3-S0004, L3-S0005, L3-S0006
    - supports CL31
  - **CL33** 太十三17 與路十24 記同一句耶穌的話，馬太用 epithymeō，路加用 thelō（意志）；所以 epithymeō 的意思與 thelō 一樣，是意志上決定要，不只是喜歡。
    - claim_kind: exegetical
    - related_ranges: L3-S0008, L3-S0009, L3-S0031
    - supports CL31
    - **CL34** 雅各用 epithymia 代表（很強的）慾望，沒有意志；雅各以外的新約作者（包括馬太），epithymia／epithymeō 是慾望加上意志。雅各的用字跟別人不一樣。
      - claim_kind: exegetical
      - related_ranges: L3-S0033, L3-S0035
      - qualifies CL33
  - **CL35** 犯罪的關鍵在於意志決定要做；只有慾望、沒有意志決定要做，只是引誘，還沒有犯罪（雅一14–15：私慾懷了胎才生出罪來）。
    - claim_kind: doctrinal
    - related_ranges: L3-S0032, L3-S0033, L3-S0034, L3-S0036
    - supports CL31
    - **CL36** 慾望雖然不是罪，但繼續慾望會引進罪；慾望只是試探，遇見試探要逃避、轉移目標，不可一直跟引誘開玩笑。
      - claim_kind: practical
      - related_ranges: L3-S0036
      - qualifies CL35
  - **CL37** 誤解五28 的人求神使異性看起來像石頭、木頭一樣，這種禱告神不會聽，因為神造男造女；因此他們越禱告越苦悶。
    - claim_kind: practical
    - related_ranges: L3-S0003, L2-S0020
    - supports CL31（指出反方讀法的後果）
  - **CL38** 看聖經，證據非常重要。
    - claim_kind: hermeneutical_principle
