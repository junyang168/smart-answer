## G08 證據與理性

**頂層結論**

- **CL1** 明白聖經的意思必須用理性分析、找證據，學正確的解經方法；不能把自己的主觀當作聖靈的感動。沒有證據等於沒講。
  - claim_kind: principle
  - related_ranges: L2-S0022, L2-S0023, L3-S0010, L3-S0014
  - （頂層）
  - **CL2** 聖經一句話只有一個意思；甲乙兩人都說聖靈給他亮光，對同一節聖經的解釋卻完全相反，不可能都出於聖靈；很多人把自己的主觀當作聖靈的感動。
    - claim_kind: principle
    - related_ranges: L2-S0021, L2-S0022
    - supports CL1
  - **CL3** 用正確的解經方法找證據所得到的結論，每個人都應該一樣；以弗所書四章十三節「在真道上同歸於一」指靈命長進到一個程度，眾人準確明白聖經的意思。
    - claim_kind: interpretation
    - related_ranges: L2-S0022
    - scripture_refs: 弗4:13
    - supports CL1
  - **CL4** 我們該做的事，神不替我們做；要靠聖靈的幫助，但仍要盡自己的本分，所以要自己找證據來得到正確的結論。
    - claim_kind: principle
    - related_ranges: L2-S0023
    - supports CL1
    - **CL6** 聖靈很多時候是藉著聖經的教導來引導人；以為基督徒生活什麼都不要做、完全被動才是屬靈，是錯誤的觀念——書信中約百分之四十多的動詞是命令式。
      - claim_kind: principle
      - related_ranges: L2-S0023
      - supports CL4
      - 反方：有人說基督徒生活完全被動、只靠聖靈告訴就好才是屬靈（走捷徑）。
  - **CL5** 保羅在提摩太後書二章七節要人用理性思考他所說的話：νοέω 不只是「思想」，而是用理性去分析、思考、找證據。
    - claim_kind: interpretation
    - related_ranges: L2-S0023
    - scripture_refs: 提後2:7
    - supports CL1

- **CL7** 信心與理性不相違反；理性的根基、證據做我們信仰的根基非常重要。
  - claim_kind: apologetic
  - related_ranges: L3-S0019, L3-S0023, L3-S0024, L6-S0008
  - （頂層）
  - **CL8** 真正的理性沒有預設立場：宇宙裡有沒有神、有沒有超自然，不應是預設立場，而應是找證據之後的結論；不信派先預設宇宙裡沒有超自然、沒有神，再用理性解釋聖經裡的現象，這是有偏見的理性，不是真正的理性。
    - claim_kind: apologetic
    - related_ranges: L3-S0013, L3-S0018

      - claim_kind: apologetic
      - related_ranges: L3-S0014, L3-S0015, L3-S0016, L3-S0017
      - supports CL8
      - 反方：口試中的無神論教授認為相信有神就是迷信、不該通過。
  - **CL10** 保羅傳福音是要攻破一切反對神的錯誤觀念，把人的理性抓來歸服神；所以教會中以為有理性就不屬靈，是錯誤的。

## G09 離婚與再婚

**頂層結論**

- **CL16** 婚姻是神設立的神聖制度，不要隨便離婚；離婚不是好事，是惡，但在某種情況下，離婚是比較小的惡。
  - claim_kind: doctrine
  - related_ranges: L4-S0002, L4-S0003, L4-S0006
  - （頂層）
  - **CL17** 哥林多前書七章十五節：婚後一方先信主，信主的一方不要因此離婚；但不信的一方要離去，就讓他去，信主的弟兄或姊妹不再受婚約約束（no longer bound）；若能維持更好，因為「神召我們原是要我們和睦」，意思是盼望把還沒有信主的配偶帶到信主。
    - claim_kind: interpretation
    - related_ranges: L4-S0002
    - scripture_refs: 林前7:15
    - supports CL16
  - **CL21** 一個離過婚的人能不能在教會事奉，要看離婚是什麼緣故、是誰的錯，不可一離婚就當作犯了滔天大罪；事奉的人也要考慮事奉的效果。
    - claim_kind: application
    - related_ranges: L4-S0008
    - qualifies CL16

- **CL18** 離婚以後是否可以再婚，保羅沒有明講；但古時被離婚的女人必須再婚才能生活，離婚後再婚被認為理所當然，所以聖經不必提（如上課不必提醒人呼吸）。
  - claim_kind: interpretation
  - related_ranges: L4-S0006, L4-S0007, L4-S0013
  - scripture_refs: 林前7；申24:1–4
  - （頂層）
  - **CL19** 馬太五章三十二節「就是叫她做淫婦」：被休而沒有再婚的女人並沒有做淫婦；古時女人只能回父家或再婚才活得下去，丈夫不是為淫亂的緣故休妻、遺棄她，就是逼她再嫁別人。
    - claim_kind: interpretation
    - related_ranges: L4-S0002, L4-S0006
    - scripture_refs: 太5:32
    - supports CL18
    - **CL20** 念聖經必須了解當時的背景與文化情況；習慣了現在的情況而忘記古時的情況，會引起對聖經錯誤的觀點。
      - claim_kind: principle
      - related_ranges: L4-S0013, L4-S0006
      - supports CL19

**Questions**

- 已回答：L4-S0002「等下我回來講這句話到底什麼意思，為什麼『緣故』」→ CL19 回答。
- 未回答：會眾問馬太十九章三至九節（馬可十章二至十二節）耶穌說「起初並不是這樣」，是否暗指不可離婚（L4-S0009）。
- 未回答：會眾提路加福音十六章十八節（L4-S0010）。
- 未回答：未婚姊妹可否與離過婚的人結婚（L4-S0011）。
- 未回答：L4-S0006 末「可是還有一件事，我問各位」，原文中斷。

## G14 行為就是禱告

**頂層結論**

- **CL29** 我們的行為是我們禱告的一部分：禱告有用口講的，也有用行為表達的；行為與口裡的禱告相反，神要聽哪一個？
  - claim_kind: interpretation
  - related_ranges: L5-S0014, L5-S0018
  - scripture_refs: 太6:8–7:11
  - （頂層）
  - **CL30** 馬太六章八節（沒有祈求以前父早已知道）到七章十一節（神必垂聽禱告）首尾都講禱告，構成禱告的 inclusio，表示整段是一個單元，內容都關於禱告；其中六章九至十三節是主教導我們的禱告文，六章十九節至七章六節講我們的行為。
    - claim_kind: interpretation
    - related_ranges: L5-S0013, L5-S0014, L5-S0018
    - scripture_refs: 太6:8；太6:9–13；太6:19–7:6；太7:7–11
    - supports CL29
  - **CL31** 要看出經文的結構（如 inclusio）才看得出「行為是禱告的一部分」；沒有看到結構就看不出來。
    - claim_kind: principle
    - related_ranges: L5-S0014
    - supports CL29
  - **CL32** 禱告「願人都尊祢的名為聖」，意思是願人都把神當作神；這樣禱告的人，價值觀以神為最有價值，行為上就會積攢財寶在天上；口裡這樣禱告，卻把財寶積在地上、不為永恆積蓄，這禱告是假的。
    - claim_kind: interpretation
    - related_ranges: L5-S0018
    - scripture_refs: 太6:9；太6:19–21
    - supports CL29
  - **CL33** 禱告「願祢的國降臨，願祢的旨意行在地上」——神的國就是神作王——這樣禱告的人，行為上也會積攢財寶在天上，並對神有專一的心，因為只有神最有價值。
    - claim_kind: interpretation
    - related_ranges: L5-S0018
    - scripture_refs: 太6:10；太6:19–24
    - supports CL29

## G17 論斷與評估

**頂層結論**

- **CL36** 「不要論斷人」不是不要評估人：論斷是沒有證據就判斷、決定一個人是好是壞；評估是找證據、根據證據來衡量；聖經叫我們不要論斷人，但要我們評估一些人，不評估一定出問題。
  - claim_kind: interpretation
  - related_ranges: L6-S0009
  - scripture_refs: 太7:1–5
  - （頂層）
  - 反方：很多基督徒以為評價員工工作好不好就是論斷。
  - **CL37** 馬太七章六節「不要把聖物給狗，也不要把珍珠丟在豬前」，不評估就不知道誰是狗、誰是豬；所以七章一至五節的「不要論斷」不可能是不要評估。
    - claim_kind: interpretation
    - related_ranges: L6-S0009
    - scripture_refs: 太7:6
    - supports CL36
    - **CL38** 看聖經絕對不能忽略前後文，前後文絕對不會衝突。
      - claim_kind: principle
      - related_ranges: L6-S0009
      - supports CL37
  - **CL39** 主禱文「免我們的債」與七章一至八節「不要論斷人」平行：如果你求神免我們的債，你就不要論斷別人。
    - claim_kind: interpretation
    - related_ranges: L6-S0009
    - scripture_refs: 太6:12；太7:1–8
    - supports CL29（G14：行為是禱告的一部分；此為禱告內容與相應行為的平行）
- **重用 CL35**（statement 不變）：追加 L6-S0009（倚靠神求日用的飲食就不要憂慮，神一定供給；但要盡本分為退休後的生活計劃、預備，那不是沒有信心）。

**Questions**：無。

**留作材料、不立 Claim**

## G19 希伯來的說法

**頂層結論**

- **CL45** 「神使法老的心剛硬」是希伯來（猶太人）的說法：不是神先叫法老心剛硬、再來懲罰他；是法老自己屢次心硬，而神所造人心的定律使犯罪的人心越來越剛硬，所以聖經說神使他心剛硬。
  - claim_kind: interpretation
  - related_ranges: L6-S0014, L6-S0015, L6-S0016
  - scripture_refs: 羅9:18；出7–9
  - （頂層）
  - 反方：很多人說神叫法老心剛硬來抵擋祂、又懲罰他，這種神不公義、不值得尊敬（refutes 此 Position）。
  - **CL46** 希伯來的說法：定律是神造的，按這定律發生的事，聖經就說是神做的（如地心引力是神造的，所以聖經說神叫這東西掉下來）；撒母耳記下二十四章一節與歷代志上二十一章一節講的是同一件事，不是不同說法，而是猶太人的觀念。
    - claim_kind: principle
    - related_ranges: L6-S0014, L6-S0016
    - scripture_refs: 撒下24:1；代上21:1
    - supports CL45
  - **CL47** 出埃及記中，摩西見法老後，經文先多次說法老心裡剛硬、硬著心，大約六、七次之後，才第一次說耶和華使法老的心剛硬；之後又有法老心剛硬與耶和華使他心剛硬交替。
    - claim_kind: interpretation
    - related_ranges: L6-S0015
    - scripture_refs: 出7:13, 22；8:15, 19, 32；9:7
    - supports CL45
  - **CL48** 神造我們心裡的定律是越犯罪心越剛硬；所以按聖經的說法，神叫所有犯罪、撒謊的人心剛硬，不只法老。
    - claim_kind: doctrine
    - related_ranges: L6-S0015
    - supports CL45

**Questions**

- 已回答：羅馬書九章「神叫法老心剛硬又懲罰他是否公義」→ CL45 回答。
- 部分回答：會眾問撒下二十四章一節與代上二十一章一節是否「從不同角度可有不同結論」→ CL46 回答說是同一件事、是猶太人的觀念；但「耶和華激動大衛」與「撒但激動大衛」兩者如何對應，本組沒有具體講出。

**留作材料、不立 Claim**

- 東西掉下去是地心引力：CL46 的例子。
- 出埃及記七至九章逐節經文：CL47 的經文論據。
- 第一次撒謊心跳血壓上升、第一百次臉不改色：CL48 的例子。
