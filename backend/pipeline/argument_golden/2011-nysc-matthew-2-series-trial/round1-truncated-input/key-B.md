## G08 證據與理性

- **K1 解釋聖經必須找證據；聖經一句話只有一個意思，不能把自己的主觀當作聖靈的感動。**
  - K1.1 很多人把自己的主觀當作聖靈感動：甲說聖靈告訴他這節是這個意思，乙說聖靈告訴他是完全相反的意思；聖靈不可能給兩人相反的亮光，這是矛盾，所以聖經的意思只有一個。
  - K1.2 因此必須學解經、找證據；用正確的解經方法、根據證據得到的結論，每個人都應該一樣。
    - K1.2.1 保羅說靈命長進的結果是「在真道上同歸於一」，就是每個人對聖經的認識都一樣、準確明白聖經的意思。
    - K1.2.2 他和同事對一節經文看法不同時，不吵，而是找證據；看到證據後，兩人的看法就完全一樣。
  - K1.3 我們該做的事，神不替我們做；找證據、用理性思考是我們的本分。
    - K1.3.1 曠野沒法耕種，神才天天降嗎哪；一進迦南吃了當地出產，嗎哪就停了，因為現在該自己種田。
    - K1.3.2 神故意把嗎哪降在野外、不降在口中，要人早起自己去拿。
    - K1.3.3 保羅說「我所說的話你要思想」，「思想」原文是用理性分析、思考、找證據，「主在凡事上必給你聰明」。
    - K1.3.4 聖靈很多時候是藉著聖經的教導來引導人；不念聖經只求聖靈直接告訴你，聖靈會叫你去看聖經。想走捷徑是後現代的特徵。
    - K1.3.5 說基督徒什麼都不要做、完全被動才屬靈是錯的：書信中約百分之四十五的動詞是命令式；若完全被動才屬靈，這些都可以丟掉。真正的基督徒生活是靠著聖靈的幫助盡自己的本分。
  - K1.4 基督徒要懂得處理聖經的證據，分辨、應對不信的人亂講（例如新聞記者為轟動不懂裝懂地寫「遺失的福音書」），才不會被人問倒。

- **K2 理性和信心不相違；真正的理性沒有預設立場，「神存在」應該是根據證據得到的結論；理性的根基作為信仰的根基非常重要。**
  - K2.1 不信派所謂的理性，是先預設「宇宙沒有超自然、沒有神」，再用理性解釋聖經的現象，所以解釋不了；這是有偏見的理性，不是真正的理性。
  - K2.2 真正的理性不預設立場：先說「有沒有神、有沒有超自然，我們不知道，我們來找證據」；有神存在的證據，就接受神存在。
  - K2.3 迷信有神沒有資格拿博士，但根據證據相信有神是學術，不是迷信。
  - K2.4 保羅傳福音就是要攻破反對神的錯誤觀念，把人的理性抓來歸服神；教會裡很多人卻以為講理性就是不屬靈，這是錯的。
  - K2.5 信心要用理性、邏輯思考：亞伯拉罕得的應許是子孫必從以撒而出，以撒還沒結婚生子，神卻叫他獻以撒；他推論神會叫以撒從死裡復活，所以他用理性思考。信心需要用理性分辨、思考，得到正確的結論。
  - K2.6 理性的根基對傳福音有效：對不信者講耶穌復活的客觀證據，不用哭、不靠感情，二十個不信的人全都信主。
  - K2.7 若不好好教導青年有理性的根基、有證據，真的很危險。
    - K2.7.1 把復活等證據教給教會青年，青年在無神論教授面前站得住，進大學後百分之百持守信仰；別的教會的青年約七成離開神。
    - K2.7.2 教導真理，教會自然增長（該教會五年內增加約五倍）。
  - K2.8 解經是一切神學的根基；不懂解經就不必念神學，因為神學必須建立在聖經真理上。
    - K2.8.1 協談真正的幫助是把聖經真理搞清楚、應用在對方的困難上；只會傾聽的協談技術有用，但不是主要的幫助。很多神學院輕看解經、重協談技術，很可惜。

## G09 離婚與再婚

- **K1 婚姻是神設立的神聖制度，不可隨便離婚；離婚是惡，但在某些情況下是比較小的惡。**
  - K1.1 耶穌說「凡休妻的，若不是為淫亂的緣故……」，意思是不要隨便離婚。
  - K1.2 林前七15：已婚後一方信主、一方不信，信的一方不要主動離婚；但不信的一方一定要離去，就讓他走，弟兄或姊妹這時「不必拘束」，就是不再受婚約約束。
    - K1.2.1 能維持婚姻更好，因為「神召我們原是要我們和睦」：猶太人的這個說法，意思是對人好、希望他歸信；神巴不得不信的配偶能信主。
  - K1.3 未婚的不要與不信的人結婚：兩個背景不同的人一起生活本來就難，價值觀不同更難；「信與不信原不相配」是為我們的好處說的。

- **K2 聖經沒有明講離婚後可否再婚，因為古時被離婚的女人必須再婚才能活下去，再婚被當作理所當然；所以讀經必須了解當時的背景，不可用今天的情況去讀。**
  - K2.1 被離婚的女人若沒有再婚，並沒有做淫婦；所以「叫她做淫婦」不是說離婚本身使她成為淫婦。
  - K2.2 古時女人只有兩條活路：回父家由父親養（父親過世就沒辦法），或再婚；社會上沒有給女人的工作。
  - K2.3 所以耶穌的意思是：不是因她淫亂而休她，就等於逼她再嫁別人，叫她做淫婦；若因淫亂而休，她本已是淫婦。
  - K2.4 再婚既是理所當然，就不必提（如同上課不必提醒學生要呼吸），所以保羅也沒有提離婚後可以再婚。
  - K2.5 申二十四1–4：婦人離開夫家後可以去嫁別人；古時休書必須寫上「她可以自由結婚」，沒有這句休書就無效。
  - K2.6 我們習慣了現在的情況，忘了古時的情況，就會對聖經產生錯誤的觀點。

**材料（不是提綱上的點）**
- 經文：太五32；林前七15；林後「不要同負一軛」；申二十四1–4。
- 字義：「不必拘束」＝ they are no longer bound（中文翻譯不清楚）。
- 背景：古時女人的生存方式；休書的格式。
- 例子：約 1970 年一位離婚姊妹（丈夫提出離婚、財產全給丈夫）問能否回台事奉，他勸她不要回去，因當時台灣教會不接受離婚的人；三十多年後她退休再問，他說可以了，神學院查清她離婚的緣故後接受她，教得很好；她沒有再婚。由此說事奉要考慮事奉的效果，教會今天會評估離婚的緣故。

## G11 起誓

- **K1 耶穌說「不要起誓」，主要意思是不要用起誓來騙人，不是在任何情況下都不能起誓。**
  - K1.1 神自己也起誓：希伯來書說神為了給亞伯拉罕應許，沒有比祂更大的可指著起誓，就指著自己起誓。
  - K1.2 大祭司要耶穌起誓回答「你是不是神的兒子」，耶穌回答「你說的是」。

## G12 以眼還眼與愛仇敵

- **K1 「以眼還眼」「轉左臉」的意思是：不一定要跟惡人 get even、跟惡人作對，而是以愛對待人；以愛相待可能把對方挽回。**
  - K1.1 不一定要把左臉真的轉給人打；重點是不必人家怎樣待你，你就非怎樣待他不可。

  - K1.3 這幾段經文常被很虔誠的基督徒念錯、用錯。

## G14 行為就是禱告

- **K1 太六8 到七11 構成一個論禱告的 inclusio，所以這整段都是講禱告。**
  - K1.1 inclusio：一段經文開頭和結尾的字或觀念相同，表示這是一個整段。
  - K1.2 六8「你們沒有祈求以前……你們的父早已知道」講禱告；七7–11 講神必垂聽禱告。
  - K1.3 六9–13 是主教導我們的禱告文，不是「耶穌的禱告」（中文「主禱文」、英文 The Lord's Prayer 不太準確）。
  - K1.4 六19 到七6 講我們的行為。

- **K2 我們的行為是禱告的一部分：一種禱告用口，一種用行為；行為和口裡的禱告應當一致。**
  - K2.1 例：糖尿病人口裡求神醫治，行為上卻一直吃糖，等於用行為告訴神「不要醫我」；神要聽哪個禱告？
  - K2.2 禱告「願人都尊祢的名為聖」，就是願人都把神當作神；把神當神，價值觀就改變，最有價值的是神，所以會積攢財寶在天上。
  - K2.3 禱告「願祢的國降臨，願祢的旨意行在地上」：神的國就是神作王；這樣禱告的人，行為上會積財寶在天上，並且對神有專一的心，因為只有神最重要。
  - K2.4 口裡說「願祢的名為聖」，卻只在地上積財寶、不為永恆積蓄，這禱告是假的。
  - K2.5 沒看出經文結構（inclusio）就看不出這點；看出結構就容易看出來。

**材料（不是提綱上的點）**
- 經文：太六8；六9–13；六19–七6；七7–11。
- 定義：inclusio（前一天提過）。
- 例子：糖尿病人的禱告。

## G16 計畫與憂慮

## G17 論斷與評估

- **K1 倚靠神、求日用的飲食，就不要憂慮，神必供給；但要盡本分去計劃（如退休），這不是沒有信心，信心本身就需要這種計劃。**

- **K2 聖經叫我們不要論斷人，卻要我們評估人：論斷是沒有證據就斷定一個人好或壞；評估是根據證據來衡量。**
  - K2.1 主禱文「免我們的債」與七1–8「不要論斷人」平行：求神免我們的債，就不要論斷別人。
  - K2.2 很多基督徒把評價（老闆評員工、教授給成績）當作論斷，這是錯的，兩者差 180 度。
  - K2.3 前後文證據：七6「不要把聖物給狗，不要把珍珠丟在豬前」；不評估就無法知道誰是狗、誰是豬，所以「不要論斷」不可能是「不要評估」。
  - K2.4 讀經絕對不能忽略前後文，前後文絕不會衝突。
  - K2.5 不評估一定出問題；但不可沒有證據就一口咬定一個人是壞人或好人。

**材料（不是提綱上的點）**
- 經文：太六11（日用的飲食）、六12（免我們的債）；七1–8；七6。
- 例子：教授每學期交給註冊組的 A、B、C、D、F 成績，他在神學院用這個跟學生開玩笑。

## G18 林前十13 是警告

- **K1 林前十13 是警告，不是應許：神允許臨到的試探，神負責開出路；自己招惹來的試探，自己負責。**
  - K1.1 若十13 是應許（神必開出路叫你忍受得住），基督徒就不會犯罪；但事實上很多基督徒受試探就垮了，所以當作應許會出很多問題。
  - K1.2 十13 和十14 用「所以」連接（中文沒譯出）；「應許……所以要逃避拜偶像」不合邏輯。
    - K1.2.1 類比：「我有清潔劑能輕易洗掉手上的墨水，所以你們要特別小心不要沾到墨水」，講不通。
  - K1.3 前後文：十11 是警告，十12 是警告，十14 是警告，又用「所以」接十13，所以十13 也是警告。
  - K1.4 意思：神允許臨到你的試探，神不會讓你受不了，會替你開出路；把自己放進試探裡，犯了罪不可怪神「你的應許不可靠」，你犯罪神會懲罰。

- **K2 讀經不要憑「亮光」，要憑證據、用理性分析，才能找出一節經文真正的意思。**
  - K2.1 所謂亮光常是人的主觀亂想；A 和 B 的亮光差 180 度，不可能兩個都是亮光，一節經文不可能有兩個相反的意思。

**材料（不是提綱上的點）**
- 經文：主禱文「不叫我們遇見試探」；林前十11–14。
- 統計：他說約八到九成以上的基督徒（包括牧師、佈道家、神學院老師）把十13 念成應許。
- 類比：清潔劑與墨水。

**留下未答的問題**
- 主禱文「不叫我們遇見試探」：他說「其實試探是……」就中斷了，本組沒有講出試探是什麼。

## G19 希伯來的說法

- **K1 聖經說「神使某事發生」常是猶太人的說法：神造了萬物運作的定律，按這定律發生的事就說是神做的；「神叫法老的心剛硬」也是這樣，不是神先任意使他剛硬再懲罰他。**
  - K1.1 例：東西掉下來是地心引力拉的，地心引力是神造的，所以聖經會說神叫它掉下來。
  - K1.2 很多人讀羅九「我要叫誰剛硬就叫誰剛硬」，以為神叫法老剛硬又懲罰他，質疑神不公義、不值得尊敬；這是讀錯了。
  - K1.3 出埃及記的次序：法老一次又一次自己心裡剛硬（七13、七22、八15、八19、八32、九7），約六七次之後經文才第一次說耶和華使法老的心剛硬；之後又是法老剛硬、耶和華使他剛硬交替出現。所以不是神先叫法老剛硬。
  - K1.4 神造人的心理定律是：越犯罪，心越剛硬（第一次撒謊心跳加快很不舒服，第一百次面不改色）；這律是神造的，所以按聖經的說法，神叫所有犯罪、撒謊的人心剛硬。

**材料（不是提綱上的點）**
- 引出這話題的話：「從不同角度講可以有不同的結論」，例：撒下二十四1（耶和華激動大衛數點百姓）與代上二十一1（撒但激動大衛），講的是同一件事；他說這是猶太人的觀念。
- 經文：羅九；出七13、七22、八15、八19、八32、九7（會眾唸）。
- 例子：東西掉落與地心引力；撒謊與心剛硬（「不要舉手，舉手就多撒一次謊」）。
- 課堂事務：他眼睛不好，請會眾唸經文。

**留下未答的問題**
- 撒下二十四1 與代上二十一1（一處說耶和華、一處說撒但）怎樣用這個猶太人的說法對上，本組沒有明講。
