## G01 登山寶訓的結構

### Claims

- **CL1** 登山寶訓分為兩大段：五3–12論彌賽亞的身份；五13–七29論門徒的使命。門徒的使命中，五13–16綜合地講，五17以下闡明細節（五17–48門徒的義；六1–七11施捨、禱告等；其後是幾層結論）。
  - claim_kind: structure
  - related_ranges: L1-S0002, L6-S0018
  - 頂層
  - **CL2** 五3–12講什麼人有福，這福是彌賽亞要帶來的祝福；藉著彌賽亞所帶來的祝福，顯明彌賽亞的身份。
    - claim_kind: structure
    - related_ranges: L1-S0002, L6-S0018
    - supports CL1
  - **CL3** 聖經的觀念是：認識神、認出祂是神之後，就有行為和生命上的反應與責任；所以登山寶訓先講彌賽亞的身份，再講門徒的使命。
    - claim_kind: doctrine
    - related_ranges: L1-S0002, L6-S0018
    - supports CL1
  - **CL4** 五13–16綜合地講門徒的使命：門徒的使命就是要發光。
    - claim_kind: structure
    - related_ranges: L1-S0002, L6-S0018
    - supports CL1
  - **CL5** 五17–48講門徒的義，也就是耶穌的門徒與舊約的關係，門徒的義要勝過文士和法利賽人的義：十七至二十節講根基，然後以殺人、姦淫、報復、愛人為例。

    - supports CL1
    - **CL7** 七7–11講我們向神禱告，七12講我們要怎樣待人，兩者沒有因果關係，七12的「所以」不能接到七7–11。
      - claim_kind: exegesis
      - related_ranges: L6-S0017
      - supports CL6
    - **CL8** 七12「律法和先知的道理」要連到五17「莫想我來要廢掉律法和先知」，七12的「所以」是接這一段而下的結論。
      - claim_kind: exegesis
      - related_ranges: L6-S0017, L6-S0018
      - supports CL6
  - **CL9** 七13–27是整個門徒使命的結論；七28–29是整個登山寶訓的結論。
    - claim_kind: structure
    - related_ranges: L6-S0018

## G02 八福顯明彌賽亞是神

### Claims

- **CL11** 耶穌藉八福明講祂就是舊約所預言要來的彌賽亞，而且更進一步，這位彌賽亞是神，不是人；猶太人的觀念中彌賽亞不一定是神，但耶穌自己明知、明講祂是彌賽亞，也是神。
  - claim_kind: doctrine
  - related_ranges: L1-S0005, L1-S0007, L3-S0007
  - 頂層
  - **CL12** 耶穌講八福時引用以賽亞六十一1–2（彌賽亞要傳好信息給謙卑的人、醫好傷心的人、安慰一切悲哀的人），藉著祂帶來的祝福宣布祂就是以賽亞六十一章所預言要來的彌賽亞。
    - claim_kind: exegesis
    - related_ranges: L1-S0005, L1-S0007
    - supports CL11
    - **CL13** 以賽亞六十一1的「謙卑」（anawim）通常譯為 praus，在此卻譯成不常用的 ptochos（貧窮）；馬太五3用同一個不平常的字，證明耶穌講這句話時心中想著以賽亞六十一章。
      - claim_kind: exegesis
      - related_ranges: L1-S0005
      - supports CL12
    - **CL14** 五5「溫柔的人必承受地土」（將來）應驗以賽亞六十一7「在境內必得加倍的產業」所預言彌賽亞要帶來的祝福。
      - claim_kind: exegesis
      - related_ranges: L1-S0005
      - supports CL12
  - **CL15** 五11–12說因耶穌受逼迫的人，與「在你們以前的先知」一樣受逼迫；那些先知在耶穌來以前是因神受逼迫，所以因耶穌受逼迫就等於因神受逼迫，耶穌就是神。
    - claim_kind: exegesis
    - related_ranges: L1-S0007
    - supports CL11
  - **CL16** 只有耶穌把 Amen 放在講話前面（「Amen，我告訴你們」），代替了舊約先知所說的「神的話臨到我」；這在耶穌口中的意思是：我就是神，我以神的權柄告訴你。
    - claim_kind: exegesis
    - related_ranges: L3-S0007
    - supports CL11
  - **CL17** 有人說耶穌從來沒有說祂是神，這不對；聖經中這樣的證據一大堆，只是沒有受過訓練的眼睛看不出來，受過訓練的人應該看得出來。
    - claim_kind: method
    - related_ranges: L1-S0007
    - supports CL11

## G03 八福是天國的祝福

### Claims

- **CL18** 八福（五3–10）所應許的安慰、承受地土、飽足、蒙憐恤、見神、稱為神的兒子，全都是天國的祝福，不是普通的祝福。
  - claim_kind: exegesis
  - related_ranges: L1-S0003
  - 頂層
  - **CL19** 讀經原則：聖經常有 inclusio 的結構，一段經文的開頭和最後字或觀念完全一樣，表示這是一整段，並可藉開頭和結束知道這一段的重點。
    - claim_kind: method
    - related_ranges: L1-S0003
    - supports CL20
  - **CL20** 五3與五10都以「天國是他們的」開頭和結束，構成 inclusio，所以五3–10是一整段，重點在講天國的福；中間幾福雖沒有提天國，也都與天國有關。
    - claim_kind: structure
    - related_ranges: L1-S0003
    - supports CL18
  - **CL21** 把「哀慟的人必得安慰」解成一般人遇到痛苦將來會得人安慰，是完全搞錯；這裡的哀慟和得安慰都跟天國有關。
    - claim_kind: exegesis
    - related_ranges: L1-S0003
    - supports CL18

- **CL22** 八福的第一福和最後一福用現在式（天國現在是他們的），其他各福都用將來式；這表示虛心的、為義受逼迫的人今天就體會天國，其他的福要等將來神的國完全臨到時才體會。
  - claim_kind: exegesis
  - related_ranges: L1-S0004
  - 頂層
  - **CL23** 「天國」和「神的國」是同一件事，意思是神作王；「天國」只出現在馬太福音，因為馬太主要寫給猶太人，猶太人盡量不用「神」字而用「天」代表神。
    - claim_kind: doctrine
    - related_ranges: L1-S0004
    - supports CL22
  - **CL24** 天國（神的國）在耶穌降生、在地上的時候已經來到，是現在就有的事實；但要到將來才完全來到。
    - claim_kind: doctrine
    - related_ranges: L1-S0004
    - supports CL22

## G04 溫柔與謙卑

### Claims

- **CL25** 五5的「溫柔」就是謙卑、就是等候耶和華：謙卑的人知道神給他什麼恩賜，知道恩賜不是自己有的而是神給的，所以不驕傲；使用恩賜時需要依靠耶和華。溫柔也包括 teachable，虛心願意領教。
  - claim_kind: exegesis
  - related_ranges: L1-S0006
  - 頂層
  - **CL26** 詩篇三十七11「謙卑人必承受地土」與三十七9「等候耶和華的必承受地土」對照，顯示溫柔就是謙卑，就是等候耶和華。
    - claim_kind: exegesis
    - related_ranges: L1-S0006
    - supports CL25
  - **CL27** 有神所給的恩賜卻推說「我不會」，以為這是謙卑，其實不是謙卑，而是推辭。
    - claim_kind: ethics
    - related_ranges: L1-S0006
    - qualifies CL25
  - **CL28** 「等候耶和華」不是什麼都不做坐著等，而是知道自己不靠自己的能力做事，做事要依靠耶和華。
    - claim_kind: exegesis
    - related_ranges: L1-S0006
    - supports CL25
  - **CL29** 雅各書一21「存溫柔的心領受那所栽種的道」從前後文顯示，「溫柔」包括 teachable，就是虛心、願意領教。
    - claim_kind: exegesis
    - related_ranges: L1-S0006
    - supports CL25（亦作 CL31 的案例，見 CONNECTIONS）

- **CL30** 「承受地土」不只是得到土地，而是蒙神之福，包括神一切的恩典臨到他身上。
  - claim_kind: exegesis
  - related_ranges: L1-S0006
  - 頂層

- **CL31** 讀經原則：研究、查考聖經時要特別看關鍵字的意思，千萬不要把自己的觀念讀進那個字裡，必須從前後文找出關鍵字的意思。
  - claim_kind: method
  - related_ranges: L1-S0006
  - 頂層（由雅各書一21的案例 CL29 支持）

## G05 基督徒與摩西律法

### Claims

- **CL32** 基督徒今天不在舊約（摩西律法）之下，乃在新約、在基督的律法之下；基督的律法與摩西的律法有重疊，所以耶穌一方面說不必再守摩西律法的某些要求，一方面又說要遵行誡命，並不矛盾——「約」的觀念解決這個問題。
  - claim_kind: doctrine
  - related_ranges: L1-S0008, L1-S0009, L2-S0001, L2-S0002, L2-S0003, L2-S0004, L2-S0005, L2-S0006, L2-S0007, L2-S0017
  - 頂層
  - **CL33** 很多人以五17–18說耶穌明講舊約律法今天還要遵守，只讀「律法的一點一畫也不能廢去」而不讀「直到成全」（ἕως ἂν πάντα γένηται）；這樣讀會與耶穌廢去潔淨食物之分等話矛盾，所以這種了解不對。
    - claim_kind: exegesis
    - related_ranges: L1-S0008, L1-S0009, L2-S0001
    - supports CL32
    - **CL34** 耶穌來了之後，摩西律法至少有一部分我們不必再遵守：耶穌潔淨了所有的食物（可七19原意），廢去了潔淨與不潔淨食物的分別；神對彼得說「神所潔淨的，你不要看作不潔淨」；基督一次獻上永遠的贖罪祭，我們不必再獻贖罪祭。
      - claim_kind: exegesis

  - **CL35** 宗主國與附庸國之約（Suzerain-Vassal Covenant）：宗主國先恩待附庸國，然後對附庸國提出要求；附庸國遵守要求不能建立好關係，只能維持已有的好關係，不遵守則約破裂。

    - supports CL36
  - **CL36** 舊約是神先恩待以色列，把他們從埃及為奴之家領出來，然後在西乃山提出要求，就是摩西的律法；新約是神恩待基督徒，向基督徒的要求是保羅所說的「基督的律法」。
    - claim_kind: doctrine
    - related_ranges: L2-S0003, L2-S0004
    - supports CL32
    - **CL37** 林前九20應譯「我在神面前不是沒有律法，我乃在基督的律法之下」；保羅說自己不在摩西律法之下，乃在基督律法之下（加六2也講「基督的律法」），所以基督徒在基督的律法底下。
      - claim_kind: exegesis
      - related_ranges: L2-S0004
      - supports CL36
  - **CL38** 舊約的神與新約的神是同一位，祂的要求都是為祂子民的好處，所以摩西的律法與基督的律法有重疊的地方（不拜偶像、不偷竊、不姦淫、不殺人等）；不重疊的如獻祭、潔淨與不潔淨的食物，基督的律法不管。
