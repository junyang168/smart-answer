    - related_ranges: L2-S0022

  - **CL4** 用正確的解經方法找證據所得到的結論，每個人都應該一樣；觀點不同時不是吵，而是找證據，看了證據之後所看的就一樣。

## G09 離婚與再婚

### Claims

- **CL23** 按照聖經的教導，離婚之後可以再婚，男女一樣。
  - claim_kind: ethical
  - related_ranges: L4-S0006, L4-S0007, L4-S0010, L4-S0013
  - 頂層（主要結論）
  - **CL24** 保羅沒有明講離婚後可以再婚，是因為古時被離婚的女人找不到工作，不回父家就只能再婚才活得下去，再婚被視為理所當然，所以不必提。
    - claim_kind: historical_judgment
    - related_ranges: L4-S0006, L4-S0010, L4-S0013
    - supports CL23（另 supports CL39）
  - **CL25** 太五32「就是叫她做淫婦」：被休而沒有再婚的女人並沒有做淫婦，所以這句話的意思是：不是為淫亂的緣故休妻，就是逼她只能再嫁別人。
    - claim_kind: exegetical
    - related_ranges: L4-S0006
    - supports CL23
  - **CL26** 約四17–18 耶穌說她「已經有五個丈夫，現在有的並不是你的丈夫」，分別了她再婚過的丈夫與現在同居而非丈夫的人，表示耶穌承認再婚。
    - claim_kind: exegetical
    - related_ranges: L4-S0006, L4-S0013
    - supports CL23
  - **CL27** 申二十四1–4 婦人離開夫家以後可以去嫁別人；古時休書必須寫明「休妳之後妳可以自由結婚」才有效，表示當時認為離婚後再婚是理所當然（例外是前夫不可再娶回她）。
    - claim_kind: exegetical
    - related_ranges: L4-S0007, L4-S0013
    - supports CL23
  - **CL28** 「娶被休之婦就是犯姦淫」：再婚後第一次的性關係算是犯姦淫，但正式結婚之後她已經是你的妻子，就不再是犯姦淫；再婚不一定就是持續犯淫亂。
    - claim_kind: ethical
    - related_ranges: L4-S0010
    - qualifies CL23
  - **CL29** 今天離婚後不再婚也能活下去，情況與古時不同；但保羅說「倘若自己不能節制，就當嫁娶」（林前七9），這種情況下寧可結婚。
    - claim_kind: ethical
    - related_ranges: L4-S0010
    - qualifies CL23
  - **CL30** 沒有結過婚的姊妹要嫁給離過婚的人，不一定絕對不可：若離婚是男方的錯，要看他是否真的悔改，不悔改就不要再婚；姊妹心理上能接受他結過婚的事實才結婚，不要馬上結婚。
    - claim_kind: ethical
    - related_ranges: L4-S0011
    - qualifies CL23
  - **CL31** 離過婚的人再婚後再離婚的機率比從未離婚的人高，所以教會有責任好好教導再婚者，使新家庭穩固；只要離過婚教會就不接受，那更慘。
    - claim_kind: practical
    - related_ranges: L4-S0007
    - qualifies CL23
    - **CL32** 教會看離婚的人，應查明離婚的緣故、是誰的錯，不應一離婚就當作犯了滔天大罪。
      - claim_kind: practical
      - related_ranges: L4-S0008
      - supports CL31

- **CL33** 離婚不是好事，離婚是惡；但在某種情況底下，離婚是比較小的惡。
  - claim_kind: ethical
  - related_ranges: L4-S0002, L4-S0003, L4-S0006, L4-S0009, L4-S0010
  - 頂層（主要結論）
  - **CL34** 婚姻是神設立的神聖制度，神非常看重家庭；耶穌說不要隨便離婚。
    - claim_kind: doctrinal
    - related_ranges: L4-S0002
    - qualifies CL33
  - **CL35** 耶穌說「起初並不是這樣」（太十九、可十）和路十六18，講的是理想的原則：結婚就是一輩子、不離婚；保羅把耶穌的這個原則用在實際的情況底下。
    - claim_kind: exegetical
    - related_ranges: L4-S0009, L4-S0010
    - supports CL33
    - **CL36** 摩西因為人心硬才准寫休書；因為人心硬、不聽神的話，才出現大惡小惡的問題，若都遵行神的話就不會離婚；做倫理抉擇時逃不掉這個問題。
      - claim_kind: ethical
      - related_ranges: L4-S0009, L4-S0010
      - supports CL35
  - **CL37** 林前七15「都不必拘束」意思是不再受婚約的約束：已婚者其中一方信主後，不信的一方要離去，就讓他走，信主的弟兄或姊妹已不再受婚約約束。
    - claim_kind: exegetical
    - related_ranges: L4-S0002
    - supports CL33
    - **CL38** 信主的一方不應因自己信主而休掉不信的配偶；保羅說能維持更好，「神召我們原是要我們和睦」是猶太人的表達法，意思是盼望那還沒有信主的配偶能信主。
      - claim_kind: exegetical
      - related_ranges: L4-S0002
      - qualifies CL37
    - **CL39a** 還沒有結婚的人不要跟不信的人結婚（「不要同負一軛」），因為婚姻本身已難，價值觀完全不同的兩人一起生活更困難；保羅這樣講是為了我們的好處。
      - claim_kind: ethical
      - related_ranges: L4-S0002
      - qualifies CL37

- **CL39** 念聖經必須了解當時的背景和文化情況，才能正確了解聖經的意思；我們常常習慣了現在的情況而忘記古時候的情況，以致對聖經產生錯誤的觀點。
  - claim_kind: hermeneutical_principle
  - related_ranges: L4-S0013, L4-S0006
  - 頂層（主要結論；CL24 的案例支持它）

- **CL40** 多妻根本違反聖經的原則；但做倫理抉擇必須考慮既成事實，不可要求已多妻而信主的酋長把其他妻子都休掉；多妻不是好見證，所以不可做教會長老、監督。
  - claim_kind: ethical
  - related_ranges: L4-S0011
  - 頂層（順帶回答的判斷）
  - **CL41** 多妻與再婚的情況不一樣：因妻子外遇的錯而被離婚、後來再婚的人，若夫婦都愛主、見證好，可以繼續在教會事奉；一個人現在的見證最重要。
    - claim_kind: ethical
    - related_ranges: L4-S0011
    - qualifies CL40

- **CL42** 考慮事奉時，要考慮事奉的效果和所去地方的情況：1970 年左右台灣教會還不能接受離婚的人擔任工作，現在態度改變，會評估離婚的緣故。
  - claim_kind: practical
  - related_ranges: L4-S0008, L4-S0011
  - 頂層（順帶回答的判斷）
  - **CL43** 領導力是對別人的影響，人對你的尊敬是你贏得的，要做給人家看，不是因為被派到那個位置人家就非聽不可。
    - claim_kind: practical
    - related_ranges: L4-S0011
    - supports CL42

## G10 兩害取其輕

### Claims

- **CL44** 在倫理抉擇上，有時不管走哪一條路都是惡，沒有辦法避免一切的惡；這時只有選擇比較輕的惡去做，聖經確實有這種選擇小惡的例子。
  - claim_kind: ethical
  - related_ranges: L4-S0004, L4-S0005
  - 頂層（主要結論）
  - **CL45** 彼得教導要為主的緣故順服人的一切制度（彼前二13），但公會禁止奉耶穌的名講道時，他寧可順從神；違背公會是惡，違背神是更大的惡，所以他選擇較小的惡。
    - claim_kind: exegetical
    - related_ranges: L4-S0004
    - supports CL44
  - **CL46** 喇合撒謊是惡，把兩個探子交出來被殺是更大的惡，所以她選擇小的惡；聖經沒有因她撒謊定她的罪，神拯救她，她後來成為耶穌的先祖。
    - claim_kind: exegetical
    - related_ranges: L4-S0004
    - supports CL44
  - **CL47** 分辨哪個是大惡、哪個是小惡，需要從客觀的情境、從神整個的公義去看；當事人自己決定比較難，應找屬靈的長者討論，幫助自己思考。
    - claim_kind: ethical
    - related_ranges: L4-S0005
    - qualifies CL44
  - **CL48** 胎兒只是有可能有問題時，不要墮胎：墮胎是把一個生命墮掉，是惡；孩子生下來真有問題，還可以考慮送到專門收養這類孩子的地方，並要找別人一起分析。
    - claim_kind: ethical
    - related_ranges: L4-S0005
    - qualifies CL44

## G19 希伯來的說法

### Claims

- **CL97** 按照猶太人的說法（聖經的說法），神所造的定律所產生的結果，可以說成是神做的；所以「神叫法老的心剛硬」不是神先叫法老心硬、再懲罰他。
  - claim_kind: exegetical
  - related_ranges: L6-S0014, L6-S0015, L6-S0016
  - 頂層（主要結論）
  - **CL98** 東西掉下去是地心引力拉下去的，地心引力是神造的，所以聖經就說神叫這東西掉下來。

    - related_ranges: L6-S0014
    - supports CL97
  - **CL99** 出埃及記七至九章，摩西見法老後，經文先一再說「法老心裡剛硬」，大約六、七次以後，才第一次說耶和華使法老的心剛硬；所以不是神先叫法老心剛硬。
    - claim_kind: exegetical
    - related_ranges: L6-S0015
    - supports CL97
  - **CL100** 神造我們心理的定律是越犯罪心越剛硬（例如撒謊多了就臉不改色）；所以按照聖經的說法，神叫所有犯罪、撒謊的人心剛硬。
    - claim_kind: doctrinal
    - related_ranges: L6-S0015
    - supports CL97
  - **CL101** 撒下二十四1（耶和華激動大衛數點以色列人）與代上二十一1（撒但激動大衛數點他們）講的是同一件事；這不是不同的說法，而是猶太人的觀念。
    - claim_kind: exegetical

    - supports CL97

- **CL102** 念聖經要懂猶太人講話的口氣，不懂就會把經文唸錯，就像外國人把中國人說的「我高興死了」當真。
