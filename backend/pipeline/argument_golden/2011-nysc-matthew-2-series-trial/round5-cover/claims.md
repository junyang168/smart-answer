## G05 基督徒與摩西律法

- **R1** 基督徒已經不在摩西的律法（舊約）之下，乃在新約、在基督的律法之下；基督的律法與摩西的律法有重疊的部分，所以耶穌說「無論何人遵行這誡命……在天國要稱為大的」（五19–20）、保羅書信中看起來仍要守律法的話，指的都是這重疊的部分；從「約」的觀念，就解開了耶穌一面說不必再遵守摩西律法、一面說要遵行這誡命的表面矛盾。【頂層】
  - kind: doctrinal；ranges: L1-S0008, L1-S0009, L2-S0001, L2-S0002, L2-S0003, L2-S0004, L2-S0005, L2-S0006, L2-S0007, L2-S0017
  - **B:CL1**（沿用，statement 不變）解釋聖經必須找證據、用理性分析，才能得到經文正確的意思；不能把自己的主觀當作聖靈的感動，沒有證據等於沒講。
    - 追加 ranges: L1-S0008, L1-S0009；supports R1（作前提：唸聖經不可看過去就算，要用頭腦思想、分析，才看出經文之間的問題並找出真理）
  - **R2** 耶穌來了以後，摩西的律法至少有一部分我們不必再遵守：眾先知和律法說預言到約翰為止（太十一13；路十六16）；可七19 原文是「耶穌潔淨了所有的食物」，不必再分潔淨與不潔淨的食物；基督一次獻上永遠的贖罪祭（來十12–14），不必再照摩西律法獻贖罪祭；神給彼得的異象「神所潔淨的，你不要看作不潔淨」，意思是從今以後不要再分潔淨與不潔淨的東西。
    - kind: exegetical；ranges: L1-S0008, L1-S0009, L2-S0001；supports R1
  - **R3** 五18 中文譯「都要成全」，原文 heōs an panta genētai 是「直到成全」，就是直到都發生了（參太二十四34「都要成就」）；耶穌沒有廢掉律法，但很多人不唸「直到成全」，讀成律法的一點一畫絕不能廢去、今天還要遵守，這樣讀就與耶穌潔淨所有食物、不必再獻贖罪祭的話矛盾。
    - kind: exegetical；ranges: L1-S0008；supports R1
  - **R4** 舊約、新約都是宗主國與附庸國之約，兩個要素是先施恩、後要求：舊約是神先把以色列人從埃及為奴之家領出來，然後在西乃山向他們提出要求，就是摩西的律法；新約是神恩待基督徒，向基督徒的要求，保羅叫做「基督的律法」。
    - kind: doctrinal；ranges: L2-S0002, L2-S0003；supports R1
    - **R5** 林前九20 中文譯錯，原意是「我在神面前不是沒有律法，我乃在基督的律法之下」；加六2 也說「完全了基督的律法」；所以基督徒在基督的律法底下。
      - kind: exegetical；ranges: L2-S0004；supports R4
  - **R6** 舊約的神和新約的神是同一位，祂向子民的要求都是為子民的好處，所以摩西的律法與基督的律法有重疊的地方；不重疊的部分，如獻祭、潔淨與不潔淨的食物，基督的律法不管。
    - kind: doctrinal；ranges: L2-S0005, L2-S0007；supports R1
    - **R7** 羅八4「律法的義」原文 to dikaiōma tou nomou，應譯「律法正當的要求」，不是整個律法，就是基督的律法；保羅從來沒有說基督徒要遵守摩西律法；羅十三9–10、林前六9–10 所列看起來像要遵守摩西律法，其實是兩者重疊的部分。
      - kind: exegetical；ranges: L2-S0006, L2-S0007；supports R6
  - **R8** 十條誡也是摩西律法的一部分，基督徒今天也不在十條誡之下；說「獻祭、禮節的律法不守，十條誡還要守」是錯的，會墮入安息日會、耶和華見證人的圈套——他們接著就要你守安息日。
    - kind: doctrinal；ranges: L2-S0007；qualifies R1
    - **R9** 但不在十條誡之下，不等於今天可以犯姦淫、殺人、拜偶像，因為不拜偶像、不偷竊、不犯姦淫、不殺人等，屬於基督的律法與摩西的律法重疊的部分。
      - kind: ethical；ranges: L2-S0007；qualifies R8
  - **R10** 五19–20 的「這誡命」指基督的律法，就是與摩西律法重疊的部分：廢掉其中最小的一條、又教訓人這樣做的，在天國要稱為最小；遵行又教訓人遵行的，在天國要稱為大。
    - kind: exegetical；ranges: L1-S0009, L2-S0001, L2-S0017；supports R1
    - **R11** 五20 文士和法利賽人的義有兩個特點：第一，靠自己的能力去做；第二，只在外表上遵行，心裡的本意卻與誡命的精義相反（如「我沒有拿刀殺人就好」，卻破壞人的名譽）；這就是法利賽式的律法主義。
      - kind: exegetical；ranges: L2-S0017；qualifies R10

## G07 五28 動淫念

- **R12** 五28 不是說看見異性、覺得她（他）漂亮，就已經在心裡犯了姦淫；乃是看見婦女，為了要、意志上決定要與她行淫，雖然還沒有做，在決定的那時心裡已經犯了姦淫；犯罪的關鍵是意志決定要做，只有慾望、沒有意志決定要做，只是引誘，還不是罪。【頂層】
  - kind: exegetical；ranges: L2-S0015, L2-S0024, L3-S0002, L3-S0003, L3-S0004, L3-S0005, L3-S0006, L3-S0009, L3-S0031, L3-S0032, L3-S0033, L3-S0034, L3-S0036, L4-S0012
  - **B:CL1**（沿用，statement 不變）解釋聖經必須找證據、用理性分析，才能得到經文正確的意思；不能把自己的主觀當作聖靈的感動，沒有證據等於沒講。
    - 追加 ranges: L3-S0031；supports R12（作前提：「看聖經證據非常重要」，再給更多證據）
  - **R13** 很多基督徒誤以為看見異性覺得漂亮就已犯姦淫，為此苦悶到快發神經病；求神使自己看異性像石頭、木頭一樣不漂亮，這種禱告神不會聽，因為神造男造女。
    - kind: ethical；ranges: L2-S0015, L2-S0019, L2-S0020, L3-S0002, L3-S0003；supports R12
  - **R14** 第一，五28 的 πρὸς τὸ ἐπιθυμῆσαι 是 pros to + 不定詞，在馬太和希臘文中表達目的，不是表達後果，所以是「為了要」。
    - kind: exegetical；ranges: L3-S0004, L3-S0005, L3-S0006；supports R12
  - **R15** 第二，耶穌同一句話，太十三17 用 epithymeō（先知和義人「要」看），路十24 用 thelō（意志決定要看），可見 epithymeō 與 thelō 意思一樣，不只是喜歡，而是包括意志決定。
    - kind: exegetical；ranges: L3-S0008, L3-S0009, L3-S0031；supports R12
    - **R16** 彼前四2–3 把 epithymia（情慾）與 thelēma、boulēma（意志）對應，弗二3 把肉體的私慾與「肉體和心中所喜好的」（意志）並列，顯示慾望包括意志的因子。
      - kind: exegetical；ranges: L3-S0031；supports R15
    - **R17** 只有雅各用 epithymia／epithymeō 代表單純的、很強的慾望；馬太和雅各以外的新約作者用這個字指慾望加上意志，只有慾望沒有意志不這樣稱呼。
      - kind: exegetical；ranges: L3-S0035；qualifies R15
      - **R18** 雅各與保羅、約翰等對「信」的用字也不同：信有兩個要素，(A) 根據足夠的證據接受神所啟示、可用語言表達的真理，(B) 採取與此相應的行為；雅各把 A 叫做信、B 叫做行為，所以說稱義要信加上行為；保羅、約翰等把 A 加 B 叫做「信」；他們只是用字的意思不同。
        - kind: doctrinal；ranges: L3-S0035；supports R17
  - **R19** 雅一14–15「私慾既懷了胎，就生出罪來」顯示只有私慾還沒有犯罪；有慾望而沒有意志決定要做，只是引誘；巴不得有別人的好車不是罪，決定今晚去偷，晚上還沒到就已經犯罪。
    - kind: exegetical；ranges: L3-S0033, L3-S0034；supports R12
  - **R20** 慾望雖然不是罪，但繼續慾望會引進罪；所以遇見試探要趕快逃避、轉移目標去思考別的事，不可一天到晚跟引誘開玩笑。
    - kind: ethical；ranges: L3-S0036；qualifies R12
  - **R21** 意志決定要做已經是罪，但決定要做、沒有做、真的做，在程度上不一樣；耶穌強調的是動機、意圖（intention）、意志。
    - kind: ethical；ranges: L4-S0012；qualifies R12（該段逐字稿部分標為「問」，歸屬保留不確定）
  - **R22** 追求女孩子本身不等於動淫念，要看他追是希望跟她結婚，還是只要跟她有性行為就丟掉她，兩者不一樣。
    - kind: ethical；ranges: L4-S0012；qualifies R12
  - **R23** 婚前性行為不應該，是犯罪；教會教導年輕人絕不能有婚前性行為，很重要。
    - kind: ethical；ranges: L4-S0012；掛於 R12（回答聽眾問題，只給結論、未給理由；非 R12 的論據）
  - **A:CL14**（沿用，statement 不變）只有耶穌把 Amen 放在講話前面……我以神的權柄告訴你。
    - 追加 ranges: L3-S0006, L3-S0008；掛於 R12（離題後落回的結論，不是 R12 的論據）
  - **A:CL15**（沿用，statement 不變）有些學者說耶穌從來沒有說祂是神，其實證據一大堆……

## G20（G05b）使徒行傳十五章四件禁戒

    - kind: exegetical；ranges: L2-S0014；supports R24

## G10 兩害取其輕

- **R34** 有時不管走哪一條路都是惡，沒有辦法避免一切的惡，那時只能選擇比較輕的惡去做；聖經確有選擇小惡的例子（彼得、喇合），說「惡就是惡，絕不能做」的人是沒有看到這些證據；分辨哪個是大惡、哪個是小惡，要從客觀的情境、從神整個的公義去看。【頂層】
  - kind: ethical；ranges: L4-S0004, L4-S0005
  - **B:CL27**（沿用，statement 不變）做倫理抉擇時常常逃不掉大惡、小惡的問題，人生當中不可能避免；例如政府的要求與神的命令衝突時，寧可順從神而違背政府。
    - 追加 ranges: L4-S0004；supports R34（作前提：兩個衝突，你逃脫不了）
  - **R35** 彼得在彼前二13 教導要順服人的一切制度，但公會禁止他奉耶穌的名講道時，他寧可順從神；違背公會是惡，不聽神的話是更大的惡，所以他選擇小的惡。
    - kind: exegetical；ranges: L4-S0004；supports R34
  - **R36** 喇合撒謊是惡，把兩個探子交出來被殺是更大的惡，所以她選擇小的惡；聖經沒有因她撒謊定她的罪，神因她敬畏神拯救她，她後來成為耶穌的先祖。
    - kind: exegetical；ranges: L4-S0004；supports R34
  - **R37** 當事人自己決定哪個是大惡、哪個是小惡比較難（像牙痛時說寧可死），所以應找屬靈的長者討論，幫助自己思考。
    - kind: ethical；ranges: L4-S0005；qualifies R34
    - **R38** 懷孕檢查出孩子僅僅可能有問題時，不要墮胎，因為墮胎是把一個生命墮掉，當然是惡；孩子生下來真的有問題時，也可考慮送到專門收養這種孩子的地方；這時要找別人、組內的長者一起分析決定。
      - kind: ethical；ranges: L4-S0005；supports R37（回答聽眾問題，是 R37 的應用）
  - **B:CL23**（沿用，statement 不變）離婚不是好事，離婚是惡；但在某種情況底下，離婚是比較小的惡。
    - 追加 ranges: L4-S0005；離題後落回的結論，置於 R34 下（關係方向：R34 supports B:CL23，本組原則用回離婚）

**Questions**
- 已答：現實生活中怎樣區分大惡與小惡？誰來決定？— R34、R37 answer。
- 已答：懷孕檢查出孩子可能有問題（但不一定），要不要生下來？— R38 answers。
- 未答：無。

## G15 神蹟與信心

- **R39** 聖經沒有「誠心禱告，吃下有毒的東西也不會死」這回事；提問者所指的大概是馬可福音最後一段，那段被很多人念錯，有兩個問題：抄本的問題與意思的問題；很多人沒有把聖經真的意思念出來，就產生極端的做法，破壞教會的見證。【頂層】
  - kind: exegetical；ranges: L5-S0015, L5-S0016, L5-S0017
  - **R40** 抄本的問題：很早的手抄本沒有可十六9–20，馬可福音到十六8「因為她們害怕」就結束；9–20節是很以後的手抄本才有，可能是抄寫時加進去的。
    - kind: exegetical；ranges: L5-S0016；supports R39
  - **R41** 意思的問題：那段不是說有信心就可以故意喝毒、拿毒蛇而不受害——故意喝毒一定死；而是神有時有能力顯神蹟，保守被迫、或不知不覺、不是故意碰到毒或被毒蛇咬的人，如保羅在米利大島被毒蛇咬沒有死。
    - kind: exegetical；ranges: L5-S0016；supports R39
  - **R42** 聖經沒有念清楚，就出來很多很極端的東西（如肯塔基礦工社區的教會在聚會中傳玩毒蛇，很多人被咬死），破壞教會的見證。
    - kind: practical；ranges: L5-S0016, L5-S0017；supports R39
    - **R43** 信是有內容、有對象的（信耶穌基督），不是「我信就有了」；來十一1「信是所望之事的實底」也被很多人念錯。
      - kind: doctrinal；attribution: 教授引述許牧師當天的話並表認同，「沒有這回事」是教授自己的判斷；ranges: L5-S0017；supports R42
