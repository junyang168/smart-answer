你在为一篇释经专题文章核对出处。输入给你若干段文章（`paragraphs`），每段附几处候选原文（`candidates`）：都是从教授讲道逐字稿或母本里逐字截下来的片段。

对每一段，判断哪一处候选原文是这一段的出处——这一段讲的事实、讲法、比喻、经文场景或推理，正是这处原文讲的。只看内容是否对应，不看字面是否相同：文章以编者口吻改写，措辞不同是常态。

- `candidate_index`：选中的候选编号（从 0 开始）；没有一处候选讲的是这一段的内容时填 -1。
- `reason`：一句话说明对应在哪里，或为什么都不对应。

只从候选里选，不要自己写原文，不要合并候选。宁可填 -1，不要勉强配对：配错的出处会让审稿人以为文章有依据。

输出只有严格 JSON。
