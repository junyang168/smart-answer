來源與引用校驗錯誤須為零。正式完成要求每項必要教導、理由與限定均 covered，無改變意思的 missing、merged、extra 或未解錯邊。補充細節另列；缺失若損害推論或語義，按必要項處理。通過評測仍須標明實際範圍和候選身分。

## 3. 計分與回歸

每輪對每個簽定 key 項記候選節點、關係、實際原句／SVG 和盲讀步驟，分別報 covered、missing、merged、extra。covered 表示判斷、承重理由與必要限定均保留；部分覆蓋列為 missing 並寫出缺的成分。merged 指錯併後喪失語義區別，多項 key 合理放在同一節點不扣此項。extra 列出所有無據新增的主張、關係或限定。另報錯向邊、來源歸屬錯誤、重要視覺事件的漏用和未准入數。

Claim verification 每個單元核對全部節點和關係。給裁判原圖／固定 SVG、原話、結論錨點與有角色標記的支持／反方材料。報告 covered、changed、added、缺依據數及其具體位置，不用預篩零發現代替完整核查。

Round trip 先封存完整候選。盲讀者只拿節點、關係、來源歸屬與未答狀態，排除原文、SVG 原檔、圖像、key 及歷史報告。對照裁判讀完整口述與准入 SVG，逐項檢查復述。歸因核查要能同時參照原圖、原話和候選。讀者自行補出的正確答案仍記圖的缺口。兩項核查分別報告結果與用量，再作完整單元決定。

每次提示變更先定位已評分的失敗，再重跑受影響案例及既有反例。新增 criteria 須告知負責人並重評先前輪次。首講用於開發；在凍結規則後從後三講另選完整新單元，先生成封存再開對應 key，報告已見與未見範圍。每輪列實際模型、輸入／輸出／推理／快取用量與調用次數。

## 4. 必需反例與自審

| 反例 | 必需結果 |
| --- | --- |
| 全段／局部軟刪，小標題，純經文與書頁 | 保留原定位；教授教導範圍符合來源投影與引用身分 |
| 沒有 SVG 的段落或整講 | 沿正常口述入口完成，無虛構視覺證據 |
| 相同圖多次出現，及兩張獨立 build | 共用資產但保留事件與各次解說，不把關鍵中間步驟當冗餘刪除 |
| 改一個希臘字、反轉箭頭、交換諷刺／真話顏色 | 原圖核對或內容核查能指出具體變化 |
| 把反方七年時間線轉成教授正面主張 | Claim verification 與 round trip 能識別立場錯誤並定位 |
| 正文相同而 SVG 或確認版本改變 | 原有視覺依賴及審核失效，正文相同不能沿用整包通過 |
| 跨講續題、跨批重號、早換／晚換頁 | 保住承接和原講身分，拒絕悄悄覆蓋節點及錯掛圖片 |

本 key 尚未逐張完成原圖與 SVG 比較，因此現在不能宣稱已有「圖上獨有資訊」的簽定案例。首輪 key 審閱須明確選出至少一項圖文合讀的具體貢獻，例如 K2 或 K3 的配對結構，核對 SVG 的線、位置與色彩，再寫入實際應讀出的關係。這是正式實跑前的驗收準備，不以文字分類標籤替代看圖。
