# 投影片可見性與空白輸出 v1

> **讀者**：Developer、Solution architect
> **類型**：規範
> **狀態**：當前
> **與代碼對齊**：2026-10-27（核對到 40fbe227）
> **權威範圍**：轉錄 pilot 的圖片可見性輸出；不改變音訊轉錄內容，不代表視覺模型準確度已獲實片驗證。

## 1. 無投影片時輸出空白

教授單獨入鏡、空白畫面或過場沒有可見投影片時，圖片輸出為 `null`。逐字稿繼續保留，不輸出教授照片來代替投影片，也不沿用上一張圖片填補。投影片存在但被遮擋或無法讀取時，圖片同樣為空，內部狀態記為未知。

上一張投影片可以作為內部比對證據；這不構成目前畫面仍有該投影片的證據。從教授鏡頭回到投影片時重新取得可見原圖；不能推測離鏡期間的換頁時刻。

## 2. 模型判斷與資料輸出

[換頁偵測器](../../../backend/pipeline/slide_change_pilot.py) 的 `slide-pair-review.v2` 提示只注意投影片內容，忽略人物動作、表情、鏡頭移動及縮放。教授和投影片同時可見時比較投影片；僅教授畫面必須回 `not_visible`，不能因人物未動而回 `same_content`。

報告的 `visibility` 保存 `sampled-slide-visibility.v1` 時段：

| 狀態 | 圖片輸出 | 說明 |
| --- | --- | --- |
| `visible` | 原圖路徑與事件 ID | 有已取得的可見投影片 |
| `no_slide` | `null` | 模型判斷沒有投影片 |
| `unknown` | `null` | 尚未取得、遮擋或證據不足 |

無圖或未知狀態會清空目前圖片。之後只出現 `same_content` 或 `layout_change` 不足以恢復先前圖片，必須重新取得正向投影片事件。影像時間仍來自抽樣候選：可見從已審視的穩定樣本起算；無圖／未知從候選邊界保守清空，沒有宣稱逐影格精度。

## 3. 圖文組合與相容性

[圖文組合器](../../../backend/pipeline/transcript_slide_assembly.py) 驗證時段完整覆蓋音訊、無重疊或缺口，並拒絕無圖時段帶有舊圖片。`slide_at_time` 在無圖、未知及範圍外均回 `None`，顯示端應清空圖片。靜態段落插圖只掛到與該圖可見時段相交的完整段落；找不到段落時保留原事件但 `paragraph_id` 為 `null`，不挪到稍後的教授鏡頭段落。

舊報告沒有可見性時段，仍可重建原試稿，但會明示 `visibility_available=false`；不可把它當成已驗證的無投影片空白輸出。原 15 分鐘 Page 與[實測記錄](./transcript_slide_pilot_20261027.md) 保持原樣，未用新版提示重新付費辨識。

本次合計 32 個 backend 測試通過，包含教授鏡頭空白、遮擋清空、重新取得、不可沿用前圖、空白段落保留口述及錯誤資料拒絕。這些以指定分類驗證輸出規則；尚未新增教授入鏡實片的視覺辨識評測。通用投影片定位與跨鏡頭的上一張圖片比較輸入仍屬後續工作。
