## 1. 对任何主题先盲读，再核对来源

冻结完整单元、生成配置和论证层候选。给一个未看过该单元的独立读者开新会话，只给中性题目、候选节点的陈述、关系及其理由、归属与未答状态。排除逐字稿、原句栏、可打开原文的工具、同工材料、评分要点和以往报告。题目只指出要复述的主题。读者用自己的话写出教授讲到哪里、每一步凭什么，标出所据节点和关系，把需要自己补的地方列出来。先封存读者实际收到的材料和复述，再做来源核查。

评审先按冻结原文列出教授实际给出的判断、关键理由、适用条件和未答之处，再逐步核对复述。既查必要内容是否遗漏，也查每项说法是否有论证层依据、是否忠于原文。接受等义复述、多条依据汇合及一条记录内已讲清的简单判断。教授只作判断时，忠实保留这一点即可。若读者补出的理由碰巧正确，仍须记录论证层没有交代。报告区分候选遗漏、候选错连和读者漏读，标明可复查的位置。

系列三的长、短两题用于开发和回归。检验能否迁移时，在查看候选之前从其他主题中另选未用于此次设计或调提示的完整单元，记录选择理由、来源范围和中性题目。选材应覆盖不同的讲法，例如直接回答、借例子说明，或几条独立理由汇合。冻结同一套生成与盲读提示后逐题运行，分别报告结果及尚未检验的讲法。某题一旦用于改提示，就归入开发案例；下一次验证迁移须另取未见主题。

## 2. 系列三开发案例的固定材料

共同输入为 2012 NYSC《马太福音释经（三）》第四讲 S0009–0011、第五讲 S0001–0043、第六讲 S0001–0012，顺序如录音。这里的 S 是冻结版本中从 1 开始的口述段号，时间是段落起点。取足 58 个整段，连转场、插问和短暂岔题一起交给生成器，让它自己判断归属。两题从同一次输出判读。讲题、人工试分的组、下表、同工 PPT 和既有候选均只给评测者。生成时只给原文、出处与通用任务。

[盲测协议](../../../backend/pipeline/argument_golden/2012-nysc-matthew-3-parables/blind-protocol.json)固定三份原件的 SHA-256、当时的提示与模型配置。[离线核对](../../../backend/pipeline/argument_golden/2012-nysc-matthew-3-parables/verify_blind.py)能从这些原件重建相同的 58 段输入。源版本变化时另记试验版本，保留原比较。这里已知同工分享的结构，后续对本例的改进只能报告为开发集结果。评估迁移能力时，再用一个未参与设计的单元先生成并封存，再开参考答案。

## 3. 从终点向前查，再从开题向后查

评测者先从输出的总回答沿关系回到各自的依据，再从教授留下的问题走到后来实际作答的地方。在候选上记下沿用的节点、边、解释和原句。等义措辞、单步或多步均可。若同一条记录已经写全一段简单推理，从记录的陈述即可复述，评审另查引文。复杂依赖也可在一个步骤内明确表述，但必须能取出两端、各自出处及二者的关系。仅能靠评测者自行补出的一步记为缺失。

| 项 | 根据逐字稿应当能复原什么 | 能识别的错误 |
| --- | --- | --- |
| C1 总回答 | 六 S0012（31:47）明确区分马太所述原因与马可所述目的。偏见使直接明说难被接受；先听见、看见，虽未全懂，后来仍可能回转。 | 把「或许」写成人人最终都会回转，或颠倒原因和目的。 |
| C2 开题与马太的推理 | 四 S0011（49:36）留下太 13:15 的翻译作业。五 S0011、S0016、S0018–0019、S0025 用四个虚拟式和「医治」的直陈式解释为何读作「或许」；人的回转尚未确定，一旦回转，医治确定。能从作业追到回答。 | 只引第五讲复述；只给译词；把回转条件丢掉。 |
| C3 马可的难处 | 五 S0033–0040 将可 4:10–12 和 4:33–34 同按耶稣惯常的做法对读。「叫人听不懂」与「照他们所能听的」相冲突；「有耳可听」等上下文帮助判读。 | 列出两组经文，未说明为什么可比或矛盾在哪里。 |
| C4 解难 | 五 S0041–0043 至六 S0001–0002。「确实看见、听见」「虽然尚未明白」「或许回转得赦免」共同构成教授的读法；须指出它怎样解开 C3 的矛盾。 | 两处都有摘要，仍要读者自己猜哪项困难得到解答。 |
| C5 回到总回答 | 六 S0004–0005、S0012 说明直接讲身份会引起拒绝。读者能分别追回原因的依据、语气怎样限定结果，以及 C4 怎样说明目的。 | 结论正确，边却用「或许回转蒙医治」证明有偏见或证明采用比喻的原因。 |
| C6 插问与例证 | 五 S0021–0024 保留悔改之心插问自己的回答；六 S0005–0011 律师事例说明当面反驳、事后仍可能思想。 | 将律师当作语法证据，或把独立插问当成解开马可矛盾的前提。 |
| C7 次一级依据 | 分别查五 S0028–0032 的惯常提问、复数和解释对象，六 S0001 借语境辨义，六 S0004–0005 对直接宣告身份的反应。 | 报告具体漏掉的依据及影响，便于区别信息压缩与推理断裂。 |
| S1 简单判断 | 六 S0003（09:34）讲怎样抓住比喻的中心，仍可单独找到这项判断。 | 被长论证吞并。 |
| S2 例证与限定 | 同段以管家为将来预备说明如何取中心，应用到为永恒预备；教授明说不能据此效法撒谎或伪造文书。 | 保留故事而丢了应用或限定。 |
| S3 拆分适度 | 简单判断和这个例证彼此相连，改欠条等叙事细节留在例证内。 | 故事角色的做法被提升为教授独立倡导的 Claim。 |

同工 PPT 第 8、18 页可交叉核对整体结构，第 9–12 页对读马可，第 13–14 页对读马太。仅在上述逐字稿范围内取证。简单题直接按六 S0003 核对。

## 4. 整个单元一次生成，封存后直接验收

1. **运行范围**。使用同一份冻结原文和来源版本，通读全单元。每个组生成一次 Claim 候选，保留每组实际读到的句域、原答和原句出处。再用这些候选与单元原文生成证据步骤及有方向的关系。按负责人决定，本轮直接验收该产物。
2. **先封存**。记录单元候选摘要值、全部节点与关系、证据位置、未答问题和未落实的承接。记录实际模型请求数与输入范围。
3. **逐项判读**。按第 1 节先封存盲读复述，再核对来源。每项记「完整／部分／缺失」及候选位置。C7 分开列三处细节。查明关系方向、理由与实际引文是否一致，并单列缺失、多出或无据的连接。源码定位和端点检查另报。
4. **分别作出判断**。复杂题的 C1–C6 均须完整，C7 逐项披露；若细节缺失造成推理断裂，则相应必要项也扣下。简单题 S1–S3 均须完整。评测者需要自行补出的桥梁记缺失。本表用于开发诊断，正式 golden 评分沿用定案规则。
