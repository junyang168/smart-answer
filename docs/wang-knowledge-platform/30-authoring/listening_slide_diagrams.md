# 聆聽投影片的論證圖

> **讀者**：神學編輯、Developer。
> **類型**：規範。
> **狀態**：當前。
> **與代碼對齊**：2026-11-18（核對到 `cbac5d65`）。
> **權威範圍**：論證圖如何進入聆聽投影片，以及發布前的驗收條件。

## 1. 目標

聽眾在教授講到一條論點時看到相應的圖，也能分辨圖的作者和出處。圖隨論證層更新，播放時間取自已校對的原文。出版時連同對應的聆聽單元與章摘要一起驗收。

## 2. 選圖與署名

- 出版流程從論證庫讀目前有效的 Claim、指向它的 `supports` 連接、Observation、視覺 SourceFragment 和來源文件。圖在別講或母本時也按這條連接選入。獨立論證 Eval 的 golden keys 不參與選圖。
- 視覺片段需通過 SVG 安全校驗，完整圖檔須符合資料庫所存的 SHA-256。署名須取自同一個片段的來源證明，連同來源名稱一起傳給聆聽頁。教授展示或繪製的圖標「教授的圖」，由論點編整的圖標「整理」。缺少或互相矛盾的署名證明時，該圖不進投影片。
- A「宗主國與附庸國的約」、B「兩律法的重疊」和 D「登山寶訓（論彌賽亞／門徒的使命）」用各自核實的教授來源。C「登山寶訓的文學結構」使用編輯署名。
- 有圖的投影片在生成時只填一個 `diagram_ref`，對應論證層提供的圖。程式查這張圖是否連到本張投影片的陳述句，並帶入圖檔和署名。

## 3. 出場和播放

- 以 Claim 在保留原文中的陳述句為第一選擇。若沒有可定位的陳述句，可用投影片中直接指向該 Claim 的要點句。只有論據連接而找不到這兩種句子時，圖留待其他有陳述句的段落。
- 圖歸在含該句的投影片，沿用字幕的時間換算。圖由該句開始才顯示，包含跳播進入的情況。到了別張投影片或另一段錄音，顯示由當前錄音所包含的陳述句重新決定。
- 每張投影片有一張圖或沒有圖。各張圖跟自己的投影片播放。
- 圖和講論要點在同一張投影片上同時可見。手機也保留要點，圖可點擊放大與捲動，關閉後回到同一張投影片。

## 4. 驗收

| 案例 | 可接受結果 |
| --- | --- |
| 第 1 講的結構圖 | C、D 各自放在相關投影片。圖和要點同時可見，C 標「整理」，D 標「教授的圖」 |
| 第 2 講的 A、B | 各在自己的 Claim 陳述句出現；圖的來源標明來自其他講道 |
| 有連接但沒有保留的陳述句 | 不顯示圖；無關的 Evidence 要點不能決定出場 |
| 同張投影片被剪成兩個播出片段 | 圖只在包含出場句的播放片段顯示 |
| 更正版的論證層 | 只有在更正憑證與原始候選都相符時，才能沿用原始分組 |
| 來源證明或圖檔更動 | 署名無法確認時不選圖；已綁定的圖檔若不符 SHA-256 或安全校驗，停止建立該版本 |
| 320×568、390×844 及桌面 | 核對未到時間、跳到時間之後、切段及放大；投影片選單與播放控制可繼續操作 |
