# 文库入口：先选书卷和来源，再选章：方案

**目标：读者进王教授圣经讲论文库，先选一卷书和一个来源，看到这卷书的各章，点一章就进那一章的按章页面。**

现在的入口（`/resources/wang-repository`）是两排 tab：「綜合文章／教授原聲」和「按經卷章節／按講論主題」，下面按段落列出，如「太16:13–23 認信、磐石與天國的鑰匙…… 7 篇 · 82 分 · 23 個講題」。负责人 2026-11-04 要求改成三层：

```
书卷 + 来源  →  这卷书的各章  →  按章页面（#637 做的太 5 那一页）
```

## 一、负责人的要求

1. 读者从**圣经书卷**和**来源**来选。来源举例：紐約靈命進深會、馬太福音釋經筆記、達拉斯聖道教會。
2. 选好书卷后列出这卷书的**章**。
3. 点一章，进按章页面——就是太 5 那一页（[#638](https://github.com/junyang168/smart-answer/pull/638)，方案见 [#636](https://github.com/junyang168/smart-answer/pull/636)）。
4. **来源以后还会增加。** 来源不能写死在页面代码里。

## 二、来源从数据来

讲道目录 `$DATA_BASE_DIR/wang-knowledge-platform/catalog/sermon_catalog.json` 每篇已有 `source_category` 和 `source_category_label`（规则见[讲道目录建置](../10-extraction/sermon_catalog_ingestion.md#原始來源正規化)）。马太福音的釋經筆記在 `matthew_source_coverage.json` 里，类别是 `notes_to_manuscript`，标签「王教授釋經課筆記」。今天的数字：

| `source_category` | 显示 | 篇数 | 是什么 |
| --- | --- | --- | --- |
| `dallas_hlc` | 達拉斯聖道教會 | 147 | 主日讲道录音 |
| `nysc` | 紐約靈命進深會 | 36 | 系列讲座录音（太 5 那一页就是 2011 NYSC 系列） |
| `notes_to_manuscript` | 王教授釋經課筆記 | 太 1–16 章 | 他的释经课笔记整理成的讲稿，是文字，没有录音 |
| `external_church` | 其他教會 | 5 | 名称未记录 |
| `other`、`unknown` | 原值／來源待確認 | 17 | |

页面上的来源清单由后端按这一栏汇总出来：哪个类别在这卷书有材料，就列哪个。以后加一个来源，只要材料进了目录、带上新的 `source_category` 和标签，入口就会出现它，不改页面。

**显示名用目录里的标签，不在页面另起名字。** 负责人说的「馬太福音釋經筆記」，目录里现在叫「王教授釋經課筆記」；要改名就改目录的标签，入口跟着变。这一点请负责人定（见第六节第 1 条）。

## 三、三层页面

### 3.1 第一层：选书卷和来源

- 书卷按圣经次序排，只列有材料的书卷；旧约、新约分开。
- 来源是一排可选的标签，第一个是「全部」。选了来源，书卷只剩这个来源讲过的；选了书卷，来源只剩讲过这卷书的。
- 两者都放在网址里（`?book=Matt&source=nysc`），可以分享、可以返回。

### 3.2 第二层：这卷书的各章

- 列出这卷书的**全部章**（马太福音 1–28），不是只列有材料的章，让读者看见哪里有、哪里没有。
- 每章一行：章号、这一章在所选来源里有什么（几篇讲道、多少分钟），有按章页面的可以点。
- 没有材料的章是灰的、不能点；有材料但还没做按章页面的，见 3.4。

### 3.3 第三层：按章页面

就是太 5 那一页：按经节次序放他在所选来源里讲这一章的原声、同步幻灯，不属本章释经的部分灰色收起。网址改为按书卷和章（如 `/resources/wang-repository/matt/5`），现在的 `/audio/mat-5-1-48` 转到新网址。

一章有几个来源时，页面顶上一排来源标签，默认是读者在第一层选的那个。

### 3.4 还没有按章页面的章

今天只有太 5 有按章页面。别的章已有的东西：

- 太 16 有按段落的原声页（2016 NYSC 系列，`/audio/mat-16-13-23` 等），点进去就是它们，标「按段落」；
- 有讲道但没做任何页面的章，列出讲道篇名，链到讲道本身（`/resources/sermons/...`）；
- 釋經筆記链到笔记讲稿本身（`/resources/notes_to_manuscript_series/...`）。

按章页面一章一章做，做好一章，那一章就换成按章页面。

## 四、综合文章和按主题

综合文章是编辑根据他的讲道写成的文章，不是他的一个来源；放进来源清单，会让读者以为文章就是他的话。所以：

- 章那一层，有文章的章在行尾标「綜合文章」，点了进文章；
- 「按講論主題」保留为入口页上的另一条路（专题文章、主题），不和书卷、来源混在一起。

## 五、要做的事

1. 后端：一个接口按书卷汇总「来源 × 章 × 有什么」，来源读目录的 `source_category`；
2. 前端：入口页改成书卷 + 来源；新加章列表页；按章页面换网址，旧网址转过去；
3. 按章页面的配置（现在 `chapter_material.CHAPTERS` 只有太 5、只有 NYSC）加上来源这一维，一章可以有几个来源各自的页面。

第 3 条只改配置的形状；别的来源、别的章的按章页面怎么做（达拉斯讲道不是按章的系列，筆記是文字），各自另开卡。
