# 文库入口：先选书卷和来源，再选章：方案

**目标：读者进王教授圣经讲论文库，先选一卷书和一个来源，看到这卷书的各章，点一章就进那一章的按章页面。**

现在的入口（`/resources/wang-repository`）是两排 tab：「綜合文章／教授原聲」和「按經卷章節／按講論主題」，下面按段落列出，如「太16:13–23 認信、磐石與天國的鑰匙…… 7 篇 · 82 分 · 23 個講題」。负责人 2026-11-04 要求改成三层：

```
书卷 + 来源  →  这卷书的各章  →  按章页面（#637 做的太 5 那一页）
```

## 一、负责人的要求

1. 读者从**圣经书卷**和**来源**来选。来源举例：紐約靈命進深會、馬太福音釋經筆記、達拉斯聖道教會。
2. 选好书卷后列出这卷书的**章**。
3. 点一章，进按章页面——就是太 5 那一页（[#638](https://github.com/junyang168/smart-answer/pull/638)，方案见 [#636](https://github.com/junyang168/smart-answer/pull/636)）。
4. **来源以后还会增加。** 来源不能写死在页面代码里。

## 二、来源从数据来

**来源是讲道所属的机构或聚会**，读讲道目录 `$DATA_BASE_DIR/wang-knowledge-platform/catalog/sermon_catalog.json` 每篇的 `source_organization`（规则见[讲道目录建置](../10-extraction/sermon_catalog_ingestion.md#原始來源正規化)）；釋經筆記读 `matthew_source_coverage.json`。不用 `source_category` 当来源：「其他教會」是一个类别，不是一个来源——负责人 2026-11-04：其他教会也可能各是一个来源。今天的材料：

| 来源（入口上显示） | 篇数 | 是什么 | 现在目录里 |
| --- | --- | --- | --- |
| 達拉斯聖道教會 | 147 | 主日讲道录音 | `source_category=dallas_hlc` |
| 紐約靈命進深會 | 36 | 系列讲座录音（太 5 那一页就是 2011 NYSC 系列） | `nysc` |
| 教授釋經筆記 | 太 1–16 章 | 他的释经课笔记整理成的讲稿，是文字，没有录音 | `notes_to_manuscript`，标签现为「王教授釋經課筆記」 |
| 其他教會（名稱未記錄） | 5 | 由 Ruxin Zhang 提供，哪个教会没有记录 | `external_church` |
| 主愛中華錄音事奉 | 15 | `source` 是网址 `http://www.gtl.org`（负责人 2026-11-04 告知机构名） | `other`，`source_organization` 为空；实现时在目录规则里加一条：`gtl.org` → 主愛中華錄音事奉，同 `bctcnj.org` → 紐約靈命進深會 |
| 來源待確認 | 2 | 网站 metadata 里没有这两篇 | `unknown` |

- **入口上的来源清单由后端汇总**：哪个来源在这卷书有讲道，就列哪个。以后加一个来源，只要它的讲道进了目录、记下机构名，入口就会出现它，不改页面。
- **其他教会各是一个来源**：一篇讲道记下了教会名，它就以那个教会出现；没记下的，暂时合在「其他教會（名稱未記錄）」下，记下名字后自动分出去。以后再有只留了网址的来源，记下机构名之前以网址显示。
- **显示名在目录里定，不在页面另起名字。** 笔记的显示名改为「教授釋經筆記」（负责人 2026-11-04），改在 `backend/pipeline/matthew_source_coverage.py` 产出的标签上。

## 三、三层页面

### 3.1 第一层：选书卷和来源

- 书卷按圣经次序排，只列有材料的书卷；旧约、新约分开。
- 来源是一排可选的标签，第一个是「全部」，其余按篇数排。选了来源，书卷只剩这个来源讲过的；选了书卷，来源只剩讲过这卷书的。
- 两者都放在网址里（`?book=Matt&source=nysc`），可以分享、可以返回。

### 3.2 第二层：这卷书的各章

- **只列有讲道的章**（负责人 2026-11-04）。没有材料的章不出现。
- 每章一行：章号、这一章在所选来源里有什么（几篇讲道、多少分钟）；有按章页面的点进按章页面，还没做的见 3.4。

### 3.3 第三层：按章页面

就是太 5 那一页：按经节次序放他在所选来源里讲这一章的原声、同步幻灯，不属本章释经的部分灰色收起。网址是 `/resources/wang-repository/books/mat/5`（`books/` 一层是因为文库下已有 `[unitId]` 这个动态段，同一层不能再放 `[book]`）。原来的 `/audio/mat-5-1-48` 照旧能打开，同一个组件。

一章有几个来源时，页面顶上一排来源标签，默认是读者在第一层选的那个。

### 3.4 还没有按章页面的章

今天只有太 5 有按章页面。别的章已有的东西：

- 太 16 有按段落的原声页（2016 NYSC 系列，`/audio/mat-16-13-23` 等），点进去就是它们，标「按段落」；
- 有讲道但没做任何页面的章，列出讲道篇名，链到讲道本身（`/resources/sermons/...`）；
- 釋經筆記链到笔记讲稿本身（`/resources/notes_to_manuscript_series/...`）。

按章页面一章一章做，做好一章，那一章就换成按章页面。

## 四、综合文章和按主题

综合文章是编辑根据他的讲道写成的文章，不是他的一个来源；放进来源清单，会让读者以为文章就是他的话。所以：

- 章那一层，有文章的章在行尾标「綜合文章」，点了进文章；
- 「按講論主題」保留为入口页上的另一条路（专题文章、主题），不和书卷、来源混在一起。

## 五、要做的事

1. 后端：一个接口按书卷汇总「来源 × 章 × 有什么」，来源读目录的 `source_category`；
2. 前端：入口页改成书卷 + 来源；新加章列表页；按章页面换网址，旧网址转过去；
3. 按章页面的配置（现在 `chapter_material.CHAPTERS` 只有太 5、只有 NYSC）加上来源这一维，一章可以有几个来源各自的页面。

第 3 条只改配置的形状；别的来源、别的章的按章页面怎么做（达拉斯讲道不是按章的系列，筆記是文字），各自另开卡。

## 六、实现

- **接口** `backend/api/public_repository.py`：`/public/repository/books`（来源清单与书卷）、`/books/{书卷}`（有讲道的章）、`/books/{书卷}/{章}`（各来源的讲道、按章页面）。现读讲道目录和马太福音来源地图。
- **一篇讲道归哪卷书、哪一章**看目录的 `canonical_scriptures`（它的主要经文），不看 `books`：`books` 是提到过的书卷，哥林多前书按它有 124 篇，按主要经文是 81 篇。
- **主愛中華錄音事奉**：`sermon_catalog.normalize_sermon_source` 加了 `gtl.org` 一条，讲道目录已重建（重建前的目录备份在会话 scratchpad）。
- **按章页面**挂在哪个来源下：`chapter_material.Chapter.source`，太 5 是紐約靈命進深會。
- **原来的入口**（綜合文章／教授原聲 两排 tab）移到 `/resources/wang-repository/library`，新入口右上角「按講論主題」「綜合文章」进去。
- **章页面**里，有按章页面的来源嵌入原来的原声页组件（`audio/OriginalAudio.tsx`）；其余来源列出讲道或笔记，链到它们自己的页面。
