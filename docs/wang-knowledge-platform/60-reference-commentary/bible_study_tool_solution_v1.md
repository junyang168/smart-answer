# 查經工具：按經文研讀，接上王教授的講解與其他釋經書

## 目標

讓查經班按聖經章節的次序研讀經文；讀到某一段落時，能直接進入王教授講解這段經文之處，收聽原聲並同步觀看投影片；團契成員另可參看以淺白中文改寫的其他釋經書。

構想由同工於 2026 年 11 月 19 日提出，記於卡片 [#822](https://github.com/junyang168/smart-answer/issues/822)。本文定義讀者入口、經文目錄、原聲定位與驗收情境。

## 2. 網站上的定位

### 2.1 現況

「聖經學習資源」（`/resources`）下現有兩個入口：

| 入口 | 它回答什麼 | 組織方式 |
| --- | --- | --- |
| 王守仁教授聖經講論文庫 | 王教授教導了什麼 | 選書卷與來源，再選章；另有「按講論主題」「綜合文章」兩個側入口 |
| 團契查經回顧 | 本團契查過什麼 | 按每次查經 |

文庫是一座**收藏**：它按講論的來源與主題整理王教授的教導，讀者從「他」出發。

### 2.2 建議

**查經工具作為「聖經學習資源」下的第三個入口，與文庫並列，不放在文庫之內。**

每段經文的頁面依次呈現：

1. 經文本身；
2. 「王教授怎麼講」：凡他講解過的段落，連到既有的聆聽頁面，從他開始講解這段經文的時刻播放；公開；
3. 其他釋經書：以淺白中文改寫，標明作者與頁碼；僅限團契成員。

王教授未曾講解的段落，第 2 項不出現，也不以其他內容替代。

### 2.3 理由

**一、它回答的是另一個問題。** 文庫回答「王教授教導了什麼」；查經工具回答「這段經文該怎麼研讀」。讀者的出發點是經文，不是講者。兩種出發點放在同一個入口下，其中一種必然退居次要。

**二、它的內容不只有王教授。** 查經工具將納入 Carson 及日後的其他釋經書。若放在以王教授命名的文庫之內，讀者難以分辨哪些話出自誰；而「分清誰說的」正是本平台使命的原則（見 [Project Mission Statement](../00-overview/project_mission_statement.md)）。

**三、兩部分的讀者範圍不同。** 王教授的材料是公開的；其他釋經書僅限內部。獨立的工具可以在同一頁上分層處理公開與受限的內容，文庫則保持完全公開，不必為此增設登入。

**四、內容不重複。** 查經工具不另存王教授的材料，只讀取既有的聆聽單元與投影片，「王教授怎麼講」直接打開既有的聆聽頁面。文庫與工具是同一份材料的兩個入口。

**五、與團契查經回顧互通。** 某次團契查經研讀的經文，可以連到工具中的同一段落；工具中的段落也可以列出本團契查過這段的記錄。

### 2.4 否決這項建議的理由

多一個入口，讀者就多一處要找的地方。另一做法是把文庫的按章頁面擴充為查經工具：結構較簡單，只有一個入口；代價是 Carson 等其他釋經書會出現在以王教授命名的文庫之下，需要在頁面上反覆標明「此非王教授所說」。

## 3. 與既有裁定的關係

**使命。** 查經工具不改變文庫「收錄的是教授的講論」這一界線：其他釋經書不進文庫，也不進王教授的知識庫，只在查經工具中與他的講解並列，並各自署名。

**參考釋經書的訪問與語言。** [參考釋經書：Carson 馬太福音掃描頁的 OCR 與研讀](./reference_commentary_solution_v1.md) 於 2026-09-23 定下：Carson 只保留英文原文、不譯中文；轉寫文字只在 `/admin` 的研讀頁中閱讀，僅限編輯與管理員。2026-11-19 的裁定在查經工具中改變了這兩點：

| | 2026-09-23 | 2026-11-19（查經工具） |
| --- | --- | --- |
| 語言 | 只要英文原文 | 改寫為淺白中文供閱讀；英文轉寫仍保留為正本 |
| 讀者 | 編輯與管理員 | 團契成員（須登入），外部人士不得瀏覽 |

英文轉寫仍是正本，改寫本必須標明所據頁碼，可回查原文。轉寫與改寫一律不進 git（倉庫是公開的）。受版權保護的頁面若由模型改寫，依專案慣例交由 Gemini 處理，不在 Claude 會話中讀出整頁原文。上述文檔將在本設計定案後同步修改。

## 4. 從書卷找到講解

### 4.1 入口與資料狀態

資源首頁以獨立卡片「按經文查經」呈現，說明為「查找經文的研讀資料」，按鈕為「選擇經文」。從資源卡進入選章、章內段落、讀經頁，再由「播放講解」開啟既有聆聽頁。書卷按新約、舊約及各約正典次序排列。

| 來源及發布狀態 | 目錄與搜尋行為 |
| --- | --- |
| 系列目錄已有連續釋經原始資料，尚無可公開研讀的段落 | 書卷置於可展開的「整理校對中」，灰色、文字標示、不可點；搜尋同樣說明狀態 |
| 至少一段已有校對逐字稿、相應論證層、最新已發布同步投影片及可解析的釋經索引 | 開放該卷與對應章，只列可研讀段落。一章的部分經文已整理即可開放 |
| 只有講道引用，或尚無已知連續釋經材料 | 瀏覽預設省略；精確搜尋回應「目前沒有可研讀資料」 |
| 目錄讀取失敗 | 保留查詢，說明載入失敗並提供重試；資料狀態維持未知 |

系列收錄取自文庫共用書卷目錄；哪些章可開放，從已發布段落向上彙總。每個講解入口綁定經文範圍、來源錄音、聆聽子單元、對應原文和播放起點。讀取沿用發布時的核對結果。更新音軌剪輯、逐字稿或投影片後，以相符版本重建受影響的入口；失效的入口暫停展示，其餘可用段落照常供應。

### 4.2 找章與返回

| 情境 | 手機及窄視窗 | 桌面及寬視窗 |
| --- | --- | --- |
| 一卷已開放 | 書名下直接顯示章號，一次點選即可進章 | 同樣直接顯示章號 |
| 多卷已開放 | 顯示書名，點書名在原位展開章號；一次展開一卷 | 左欄列書卷，右欄列所選書卷的章號；所選書名清晰可見 |
| 長卷、收錄稀疏 | 直接列實際可讀章號，例如詩 23、51、119 | 同左 |
| 長卷、收錄密集 | 按 1–25、26–50 等分組，只列有資料的範圍，直接切換範圍 | 章號使用較寬的格狀排列，同樣能跳至指定範圍 |

兩種版面共用頁首搜尋。支援繁簡書名、標準簡稱、空格與全形數字，例如「太5」「马太福音 第５章」。有書卷上下文時可只輸入章號；全目錄只填數字則提示補書名。完整簡稱優先，例如「約3」為約翰福音第三章。無效章號、書名不明及有效但未收錄的章各有不同回應。選書、選章、經文段落可直接連結；重新整理、瀏覽器返回、轉動手機或改變視窗寬度均保留目前書卷與章。從錄音回來保留展開的問題和閱讀位置。

### 4.3 經文與講解

章頁按經文次序列出範圍和主題。讀經頁保留完整經文；在相應位置顯示可展開的問題、適用節數及「播放講解」。整段講解可由段內多節找到，但閱讀頁同一處只顯示一次；逐節入口須有教授直接解釋該節的原文。跨章講解可從兩章抵達同一段，並顯示完整範圍。多系列確實講解同段時，展開後以問題、系列和場合區分講法。

先由系統依論證與逐字稿建立候選，再核對釋經對象、必要上下文及剪輯後的起聽位置。有歧義者由 Agent 回查原文；僅在材料無法裁定且會影響理解時請同工判斷。公開入口只送出已授權的公開材料；日後加入的團契限定資料另行檢查讀取權限。

## 5. 驗收情境

下列為設計驗收條件。長卷及多卷可用測試資料演練，正式頁面只依實際發布狀態開放。

| 情境 | 通過條件 |
| --- | --- |
| 首次來訪，只開放一卷 | 手機首屏可見第五章，一次點選進章；整理中的卷有文字狀態且不可啟動 |
| 新舊約皆有多卷可讀 | 新約在前；手機選卷再選章；桌面切換書卷後可選該卷章號，頁面及焦點顯示正確書名 |
| 詩篇稀疏與密集兩組資料 | 三章可用時直接列三章；全卷可用時能跳至 101–125 或搜尋「詩119」進入第 119 篇 |
| 精確搜尋與異常輸入 | 「太5」與繁簡全名進同一章；「約3」指向正確書卷；超範圍章、無資料、載入錯誤均有明確回饋 |
| 八福與交叉引用 | 太 5:5 顯示「溫柔的人」講解；太 5:7 可連回 5:3–10 的整段解釋；引用詩 37 的材料不因此自動成為詩 37 的逐節講解 |
| 播放及返回 | 三個八福入口各打開正確錄音與子單元，原聲、字幕、投影片對齊；返回仍在原經節與問題上 |
| 跨章與版本變更 | 從兩章抵達同一段；部分入口撤下後，其餘入口及正確章目仍可用；舊連結說明狀態 |
| 裝置與操作 | 320、390 像素寬與桌面均可完成同一任務；放大至 200% 可重排；觸控目標至少 44 像素，鍵盤可搜尋、選章、展開、返回，狀態不單靠顏色傳達 |

## 6. 開放問題

1. **團契成員的身分。** 網站目前只有編輯與管理員兩種登入角色；團契成員是新增一種角色，還是沿用既有帳號？
2. **文章與筆記。** 除原聲與同步投影片外，是否同時連結同一段經文的釋經文章與釋經筆記？
3. **其他釋經書的次序。** 先納入哪幾部？Carson 尚缺的章節（現有第十八、二十章）是否繼續掃描？
