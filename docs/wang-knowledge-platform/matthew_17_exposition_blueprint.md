# 馬太福音第 17 章釋經篇章藍圖

## 一、文件定位

本文件不是第三、第四講逐堂講稿的重新編排，而是以《馬太福音》第 17 章本身的經文次序為骨架，規劃一篇可連續閱讀、可用於教學的完整釋經篇章。

在知識平台中，本文件應遷移為第一個正式的 `CompositionPlan`，而不是長期作為沒有 ID 的自由 Markdown 判斷存在。它採用使用者要求的「以經文為中心的學術釋經體例」（即本計畫討論中所稱的 Carson-style 結構），但不以模仿特定作者措辭為目標。

建議的結構化身分：

- Publication Profile：`PP-passage-centered-academic`；
- Composition Plan：`CP-matthew-17`；
- 產品類型：`passage_lecture`；
- 主要範圍：太 16:28–17:27；
- 目標讀者：教會讀者與查經帶領者；
- 目前狀態：`candidate`，待使用者和編輯審核。

下文每項重要的「編排決策」將轉換為有 ID、理由、作用對象、依據、版本和審核狀態的 `CompositionDecision`。例如，限制 `Amen` 與「人子」的篇幅屬於 `include_briefly` 和 `link_related_unit`；太 17:22–27 尚無教授材料屬於 `defer_due_to_missing_evidence`，不是教授思想庫的錯誤，也不得由 AI 假託補寫。

整理原則如下：

1. 經文推進優先於講道發表次序。
2. 教授在第三、第四講中的材料保留為主要來源，但不保留課堂時間限制造成的重複與岔題。
3. 神學背景和生活應用只在有助於理解當前經文時簡要穿插。
4. 跨經文、需要深入展開的思想，移至主題文庫，正文只作摘要並提供連結。
5. 教授沒有講解的經文不得由 AI 假託教授補寫；應標示材料缺口，等待其他講道、筆記或人工研究補足。

## 二、現有材料的性質

目前兩份第 17 章相關文稿仍屬於「講道改寫」：

- `17 章 - 榮耀、信心` 主要整理第三講，包含太 16:28、太 17:1–5，以及大量相關神學與解經方法材料。
- `17 章 登山變像 醫治鬼附之子` 主要整理第四講，正文集中於太 17:14–21；太 17:9–13 雖在原講道中出現，卻在跨講整合時併入施洗約翰專題，沒有留在第 17 章的連續正文中。

因此，兩份文稿可以作為篇章材料庫，但不能直接視為完整的《馬太福音》第 17 章釋經。

## 四、建議的成稿結構

### 導言：從受苦預言到榮耀預嘗（太 16:27–17:1）

- 交代太 16:28 與登山變像的緊密相連。
- 說明變像不是耶穌在門徒有生之年完成再臨，而是讓三位門徒預先看見祂國度的榮耀。
- 對 `Amen` 和「那個人子」只作必要說明，並連至相應主題文章。

### 一、山上的榮耀：你們要聽祂（太 17:1–8）

1. 六天與約八天：不同計日方式並不矛盾。
2. 耶穌彰顯榮耀，摩西與以利亞談論祂在耶路撒冷的去世。
3. 彼得搭三座棚所暴露的身分誤解。
4. 光明雲彩所表示的神臨在，以及父神的宣告。
5. 詩 2:7 與賽 42:1 所呈現的君王與僕人使命。
6. 門徒懼怕、耶穌觸摸他們，最後只見耶穌。

### 二、下山的道路：先行者受害，人子也要受害（太 17:9–13）

1. 復活以前不可傳述所見異象。
2. 門徒的問題：若以利亞先來復興萬事，彌賽亞為何仍要受苦？
3. 施洗約翰就是已經來到的「以利亞」。
4. 先行者工作的成功不等於權勢者都會悔改；約翰受害預示人子受害。
5. 以一個短連結導向「施洗約翰的身分與地位」主題文章，不在此重複完整論述。

### 三、山下的失敗：小信與倚靠神的能力（太 17:14–21）

1. 父親的求助、門徒的失敗與耶穌的醫治。
2. 「不信又悖謬的世代」所指出的不只是證據不足，也是對神的抗拒。
3. 「信心小」不是信心的數量太少，而是對信心及權柄的認識不完整。
4. 門徒把所領受的權柄當作可自動運作的能力；耶穌重新把他們帶回對神的倚靠。
5. 以短連結導向「小信的跨經文神學」，不在本章重述太 8:26、16:8 等全部材料。

### 四、再次走向十字架（太 17:22–23）

- 本段目前缺少教授在第三、第四講中的直接講解。
- 待補足來源後，應說明它如何把山上的榮耀與人子的受害、死亡和復活連在一起。

### 五、君王之子的自由與自我限制（太 17:24–27）

- 本段目前缺少教授在第三、第四講中的直接講解。
- 待補足來源後，應處理耶穌作為「兒子」的身分、聖殿稅的問題，以及為免使人跌倒而自願限制自由的行動。

### 結語：榮耀、受苦與門徒的道路

- 第 17 章不只是幾個彼此分離的神蹟和問答。
- 敘事從山上榮耀移向下山後的受苦預言，再進入門徒的失敗、第二次受難預告及日常生活中的自我限制。
- 完整主線應呈現：正確認識榮耀之子，也必須接受祂受苦的使命；跟隨祂的門徒則要聽從祂、倚靠神，並在生活中放下自己的權利。

## 五、應從章內移出的深入專題

下列材料不是刪除，而是改由主題文庫承載；第 17 章正文只保留理解經文所必需的摘要和連結：

- 句首 `Amen` 的宣告公式與耶穌的神性權柄。
- 「人子」稱號的但以理書背景及其跨經文發展。
- 施洗約翰的完整身分、地位與先行者使命。
- 「小信」在馬太福音中的跨經文發展。
- 啟示錄文體、新耶路撒冷與哈米吉多頓。
- 千禧年與時代論。
- 「義」、**因信成義而非因信稱義**，以及人和神的合宜關係。
- 系統神學與以釋經為根基的神學訓練。
