# 馬太福音釋經教學文集：成書體例 v2

## 一、成書目標

本項目的直接成果，是由**達拉斯聖道教會編輯部編纂**、以王守仁教授的筆記與講授材料為思想來源的《馬太福音》釋經教學文集。王教授並未逐章撰寫本書；按《馬太福音》第一至二十八章建立連續閱讀次序，是編輯部為讀者加上的經文骨架。

成書體例不是照抄釋經課筆記，也不是按講道發表次序拼接逐字稿；它把筆記、紐約靈命進深會講道、達拉斯聖道教會講道及其他已確認來源，按經文次序重新編排。不同來源中的重複內容應合併，新增論據應補入適當位置，分歧或思想發展則須保留來源、時間與編輯說明。

但是，**第一至二十八章只是導航範圍，不是二十八個必須完成的寫作配額**。正式成篇的單位，是王教授真正講透、且已有足夠證據和論證支持的經文段落。某章可以有多篇文章，也可以只有短注、來源索引或編輯說明；若材料不足，也可以暫不成篇。書的實際形態由材料決定，不由「二十八章必須齊整」決定。

本體例的名稱是：**以經文為主線、以論證為骨架、以神學為深化、以生活應用為落點的釋經教學作品**。

本文件只定義成書後的閱讀結構與編輯紀律。已審核筆記講稿和分散於不同系列、年份與場地的講道逐字稿如何進入同一論證模型，以及兩者如何去重、補充與保留張力，見[《馬太福音釋經：來源進入論證層與跨來源整合流程 v1》](./matthew_source_to_argument_workflow_v1.md)。

### 1.1 作者與責任歸屬

- **成書作者／編纂者**：達拉斯聖道教會編輯部；
- **思想與講授材料來源**：王守仁教授；
- **教授內容**：有來源支持的經文觀察、主張、論證、應用、經歷與自述；
- **編輯內容**：選材、命名、分段、排序、詳略、跨講合併、專題轉介、導言、缺口說明及出版文字。

對外呈現不得暗示王教授曾按第一至二十八章寫成此書。所有重要編排判斷須保存為可審核、可修訂、可版本化的編輯決定。

### 1.2 成篇門檻，而不是補章任務

一段材料成為正式釋經文章，至少須符合：

1. 有足夠合格來源，可辨明教授本人的立場；
2. 核心解釋不是孤立語句，並有經文觀察或論證過程支持；
3. 已區分教授主張、反方說法、聽眾發言和編輯補充；
4. 已對齊跨講次的重複、補充、限定與張力；
5. 編輯能說明為何本段值得獨立成篇，以及為何詳寫或略寫。

不符合門檻時，不得用一般註釋知識或 AI 文字填滿章節。目錄中存在某一章，不等於該章必須產生文章。

## 二、與「Carson style」的關係

本項目借鑑 Carson 類優良釋經著作的，是以下編輯紀律：

- 經文而不是講課行程決定篇章順序；
- 先提出經文問題，再給出有證據的回答；
- 原文、文體、上下文、歷史背景和平行經文服務於解釋；
- 清楚區分經文觀察、解釋推論、神學結論和實際應用；
- 不同解釋及教授反對它們的理由應被公平呈現；
- 深入的跨經文專題不應使當前經文失去焦點。

本項目**不照搬 Carson 的內容比例或文風**。王教授的生活應用、牧養關懷、個人經歷和時代處境判斷，是理解其教學特色的重要材料；只要與經文的推論關係清楚，就不應因為一般學術註釋較少收錄而一律刪除。

因此，本書既不是純學術註釋，也不是講道逐字稿，而是兼具學術可核查性與教會教學用途的「釋經教學講稿」。

## 三、每個釋經單元的標準結構

每一章可以包含零個、一個或多個經文單元。達到成篇門檻的單元，以「經文與問題、釋經、神學意義」為核心結構；生活應用與補充材料按來源和功能選用。不得為了目錄、篇幅或欄目齊整而製造教授沒有講過的內容。

### 1. 經文與問題

- 標明本單元的主要經文範圍；
- 交代它在本章和全書中的位置；
- 明確提出本段真正需要回答的問題；
- 若問題來自聽眾，須標明是聽眾提問，而不是教授主張。

### 2. 釋經

這是正文主體，依實際材料使用：

- 段落結構與敘事推進；
- 希臘文詞義、文法及定冠詞等觀察；
- 和合本或其他譯本的翻譯問題；
- 文體、上下文和歷史文化背景；
- 平行經文及教授引用的其他聖經證據；
- 從觀察到結論的論證步驟；
- 教授所反對的解釋，以及反對理由；
- 尚未回答的問題或材料缺口。

此部分必須能追溯到筆記、逐字稿或講道的精確片段。編輯不得把反方說法、聽眾發言或教授的戲劇化代言誤標為教授自己的結論或聖經原文。

凡本段實際解釋、比較或用作論據的經文，應在相應位置直接引用必要的經文內容，不能只列章節號。引文須與教授的解釋、編輯說明及一般背景在排版和措辭上清楚區分。

王教授有來源支持的希臘文詞義、文法、定冠詞和翻譯判斷應優先保留：正文宜同時呈現必要的希臘文形式、教授如何解釋，以及該觀察在論證中所起的作用。編輯不得以一般字典知識補造教授未曾提出的原文結論。

### 3. 神學意義

神學意義回答「這段經文對基督、神國、約、救恩、信心、門徒等有何意義」。它應由本段釋經推出，而不是把整套神學預先套入經文。

- 與當前經文直接相關的神學結論可在正文中適度展開；
- 需要跨多卷經文或多篇講道才能完整說明的內容，只在本章交代必要結論，並連到專題文章；
- 同一主張在釋經篇和專題篇中可以被重用，但必須保持含義和來源一致。

### 4. 生活應用

生活應用不是每篇必備。只有當它與本段釋經或神學意義具有清楚而強的關聯時才收入；一旦收入，它就是本體例的正式部分，不是結尾附加的一句勸勉。每項應用必須保留可審核的推論鏈：

```text
原始經文處境
  → 王教授如何解釋
  → 可跨處境成立的不變原則
  → 今天的具體處境
  → 應用、限制與牧養風險
```

若中間任何一步缺失，該材料只能標為候選應用，不能直接寫成教授的定論。若與本段關聯不足，則不進入文章，但仍保存其來源與處置記錄。應用可以有實質篇幅，但不得與本段經文失去可說明的聯繫。

### 5. 補充材料

以下材料依功能進入附錄、側欄、專題、問答或思想發展記錄：

- 需要長篇說明的原文、異文和歷史資料；
- 有價值但會打斷正文的個人經歷；
- 課堂問答；
- 政治、社會和時代處境評論；
- 教授自述的學術經歷或立場變化；
- 與本章關聯較弱但值得保存的岔題。

補充材料不是次等材料，而是避免正文失焦的第二閱讀層。

### 6. 註釋

註釋是原文證據的正式存放層，不是可有可無的裝飾。王教授解經的分量很大一部分在原文、文法與經文互證上，而多數讀者不讀希臘文；若把原文材料全部寫進正文，正文會變成語言課；若因為讀者不懂而整條丟棄，本書就失去了教授最有特色的貢獻。註釋層同時解決這兩個問題。

**判定材料進正文還是進註釋，只用一個問題:刪掉這項觀察，該段結論還站得住嗎?**

| | 去向 | 寫法 |
| --- | --- | --- |
| 站不住（承重觀察） | **正文** | 用中文說明這項觀察證明了甚麼，讀者不需要認識原文也能跟上；原文詞形另置註釋 |
| 站得住（補強觀察） | **註釋** | 完整保留，供願意深究的讀者查核 |

承重觀察的例子:太 16:19 動詞是未來完成式（決定「天上先定、地上執行」而非相反）；「彼得」與「磐石」在希臘文中詞性不同（決定教會不是建在彼得個人身上）；太 16:12 的「教訓」是單數（決定兩派共有的是同一個錯誤，而不是各自全部主張）。這些刪掉之後，該段結論就只剩斷言。

補強觀察的例子:希臘文詞形與拼寫本身、時態術語、異文、譯本比較、與本段結論無關的字義背景。

**同一項觀察在正文只呈現一次。** 來源中對同一項語法事實的多次表述屬於同一觀察，其餘表述留在註釋或來源層，不得視為正文遺漏。

**格式**:使用標準 Markdown 腳註（`[^key]`），站點的 `remark-gfm` 已支援。腳註鍵以段落與主題命名（例如 `[^m16-19-perfect]`），便於審計比對。註釋段落與正文一樣需要來源標記，並應列出對應的 `evidence_step_ids`。

## 四、特殊材料的編輯路由

| 材料 | 進入正文的條件 | 其他去向 |
| --- | --- | --- |
| 個人經歷 | 能具體說明當前經文、解釋方法或應用原則 | 「王教授的經歷與說明」側欄、思想發展記錄；無實質內容的課堂閒談只留來源 |
| 政治／社會觀點 | 能區分不變的經文原則與特定時代判斷，並標明日期和處境 | 「時代處境中的應用」側欄；需事實核查者另建狀態，不以核查結果竄改教授原主張 |
| 課堂問答 | 問題直接推進本段釋經，且教授確實回答 | 獨立問答集；未回答問題不得由 AI 補答 |
| 重複講述 | 新講次帶來新的論據、限定、例證或更清楚表述 | 完全重複者合併來源，不重複正文 |
| 跨經文主題 | 只需少量背景即可理解本段 | 完整論述進專題文庫，正文提供摘要與連結 |
| 原文、文法與異文 | 該觀察是本段結論的必要依據（刪掉結論即不成立） | 詞形、拼寫、時態術語、異文與譯本比較進註釋；同一觀察不在正文重複 |
| 教授未講或未講透的經文 | 不得假託教授補寫，也不因此產生出版義務 | 保留來源索引、編輯說明或「尚無足夠材料」狀態；日後有新材料再評估 |

## 五、篇幅比例是指引，不是硬性配額

單元可參考以下比例：

- 釋經：約 55–65%；
- 神學意義：約 15–20%；
- 生活應用：0–25%（只有存在合格且與本段高度相關的推論鏈時才收入）；
- 補充材料：按需要另計。

比例不得成為刪除重要材料或填充空白的理由。某段若教授主要處理原文問題，釋經比例可以更高；某段若教授從經文形成完整牧養推論，應用可以更長。真正的門檻是來源、邏輯和與當前經文的關聯。

## 六、來源忠實與編輯歸屬

成稿中的內容必須區分三種聲音：

1. **教授明確主張**：有合格來源和說話者、立場、錨點資訊；
2. **編輯綜合**：例如段落順序、詳略、轉介專題和敘事高潮，必須保存為 `CompositionDecision`；
3. **一般背景或事實核查**：不得冒充教授原話，並與教授主張分層保存。

文章因此不是知識庫的機械投影，而是編輯使用共享知識庫完成的一部新作品。每個重要的選材、排序、詳略和轉介決定都必須可以審核、修訂和版本化。

文章可以不采用某项材料，但知识库不得让它静默消失。与当前经文没有足够关系的材料，应登记为 `source_only`，明确 `article_inclusion=false`，保留其主张、证据和精确来源，并转入 `requires_human_verification`。人工认证前，它可以保存在由 manifest 明确绑定、带内容指纹的待认证知识记录中；认证通过后才并入 active shared knowledge。人工认证决定它以后是否进入释经方法、专题研究或只保留为来源；这类记录不构成本篇文章的出版义务。

## 七、對應的 Publication Profile

正式 Profile 已建立於：

`backend/config/publication_profiles/PP-matthew-expository-teaching-v1.json`

它是本產品體例的中央規則來源。初稿 Manifest 只能引用 `publication_profile_id`，不得自行設定 `required_top_level_sections` 或 `optional_top_level_sections`，以免被審核稿件自己決定審核標準。

目前 Profile 為：

- `profile_id`: `PP-matthew-expository-teaching-v1`
- `product_type`: `passage_lecture`
- `primary_axis`: `scripture`
- `required_sections`: `經文與問題 / 釋經 / 神學意義`
- `optional_sections`: `生活應用 / 附錄 / 註釋`
- `original_language_policy`: 承重的原文觀察進正文並以中文說明其論證作用；詞形、拼寫與時態術語進註釋；同一觀察正文只出現一次
- `tone`: 平和、清楚、有論證，不保留課堂誇張口吻
- `application_gate`: 必須保存「經文處境 → 解釋 → 原則 → 目標處境 → 應用」
- `application_policy`: 應用鏈由內容觸發，不由標題觸發；提出今日處境與行動建議的段落必須宣告 `application_chain_id`，`editorial_synthesis` 段落則須宣告鏈或 `"contains_application": false`
- `topic_policy`: 深入的跨經文論述轉介專題，不在章內重複展開
- `authorship`: 編輯部編纂；王教授為思想與講授材料來源
- `coverage_policy`: 1–28 章是導航骨架；只讓達到成篇門檻的段落進入正文
- `gap_policy`: 教授未講或未講透之處可不成篇，不由 AI 假託補寫，也不以齊章為完成標準
- `status`: `candidate`，經編輯審核後升級

Profile 同時要求正文逐段保存來源歸屬：

- 教授觀點段落必須映射到共享 `claim_ids`；
- 經文引文段落必須保存 `scripture_refs`；
- 編輯補充段落必須在讀者可見文字中標示「編輯說明」「編輯導讀」「編者按」或「資料說明」。

這是全文反向檢查，不依賴寫作方事先申報哪一段可能有問題。任何未映射的實質段落都不能通過程序化審計。

逐段歸屬以 `<!-- provenance: {...} -->` 寫入 Markdown 源文件，供機器審計與後續追溯使用；它不是正文，也不得出現在管理端閱讀預覽或公開出版物中。呈現層只移除顯示副本中的機器註解，原始 Markdown 必須完整保留。編輯部的可見署名仍由正文中的「編輯說明／編輯導讀／編者按／資料說明」承擔，不能因為已有隱藏標記而省略。

## 八、體例驗收

每篇達到成篇門檻的稿件至少應通過以下檢查：

1. 是否按經文而非講道時間順序推進；
2. 每個主要問題是否得到清楚回答；
3. 教授引用的跨經文證據是否被保留並正確歸屬；
4. 原文、譯本、文體和歷史論據是否服務於結論；
5. 神學意義是否由本段釋經推出；
6. 若收入生活應用，每項應用是否具有完整推論鏈；
7. 個人經歷與政治評論是否進入正確閱讀層；
8. 重複材料是否合併，新論據是否保留；
9. 是否拒絕為了補齊章節而把薄弱材料擴寫成完整文章；
10. 讀者能否從文章回到精確的筆記、逐字稿或講道片段。
11. 初稿是否通過程序化審計：篇章決定完整映射、所用主張存在、每條主張至少有一項合格支持證據，且來源版本與錨點仍然有效。
12. 未进入文章的实质材料是否有明确处置记录；标为 `source_only` 的材料是否仍可追溯并已进入人工认证队列。
13. 凡正文解释、比较或用作论据的经文，是否已在相应位置直接引用必要内容；教授有来源支持的希腊文解释是否被保留并正确归属。
14. 每個實質段落是否已反向映射到教授主張、聖經原文或明示的編輯聲音；是否存在未申報、未映射的編輯推論。
15. 必備與可選章節是否來自中央 Publication Profile，而不是由本稿 Manifest 自行指定。

經卷目錄本身另須檢查：沒有正式文章的章節，是否如實顯示來源、短注或編輯狀態，而不是製造「尚欠一篇文章」的完成壓力。

第 11 項是機械門檻，不是出版批准。程序無法判斷文章是否真正回答了讀者問題、詳略是否合宜、神學表述是否清楚，或生活應用是否具有牧養智慧；這些仍由編輯閱讀決定。程序化規則、結果分級及太16:1–12 首輪驗證見[《釋經初稿的程序化審計流程 v1》](./editorial_draft_audit_workflow_v1.md)。
